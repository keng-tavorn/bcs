# ADR-001: ชื่อ Companion App คือ BCS Go

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: ตารางเรื่องที่ต้องตัดสินใจในเอกสารต้นทาง (spec §18.1 · ภาคผนวก C: เอกสารต้นทางหัวข้อ 14 "เรื่องที่ต้องตัดสินใจ")

## บริบท

- ชุดผลิตภัณฑ์ของ BCS มี 4 ส่วน: BCS Workspace (เว็บ ทำงานหลัก) · BCS on LINE (LINE OA + LIFF) · BCS Go (PWA → Capacitor) · BCS Supplier Portal (§1.2)
- spec ไม่ได้บันทึกเหตุผลของการเลือกชื่อนี้

## การตัดสินใจ

> ชื่อ Companion App คือ BCS Go

- BCS Go คือแอปเสริมบนมือถือ เริ่มเป็น PWA แล้วห่อเป็นแอปด้วย Capacitor ใน S15 (§1.2 · NG-3 · ADR-002)
- รุ่น Capacitor คือโมดูลเสริม `BCS_GO` (ต้องมี `CORE` · เปิดได้ตั้งแต่ S15) และ FR-PLT-301: ตรวจรับออฟไลน์ สแกน barcode biometric และ push (§4.11 · §8.11)

## ผลที่ตามมา

- ใช้รหัสโมดูล `BCS_GO` ในโค้ดและการเปิดปิดโมดูล (ADR-034)
- งานออฟไลน์จริงและสแกน barcode รอ BCS Go ไม่ทำใน PWA ชั้น 1 (§9.7)
- ข้อสังเกต: manifest ของ PWA ชั้น 1 กำหนด `name` "BCS Workspace" และ `short_name` "BCS" (§9.7 · FR-PLT-005) ส่วนแผนภาพ §4.1 เรียก PWA ว่า "BCS Go (PWA)" · spec ไม่ได้ระบุว่าชื่อบนหน้าจอหลักจะเปลี่ยนเป็น BCS Go เมื่อใด ระหว่างนี้ค่าใน manifest เป็นไปตาม §9.7
