# ADR-005: ตั้งค่า workflow ด้วยฟอร์มใน S6 และแบบลากวางใน S15

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: ตารางเรื่องที่ต้องตัดสินใจในเอกสารต้นทาง (spec §18.1 · ภาคผนวก C: เอกสารต้นทางหัวข้อ 14 "เรื่องที่ต้องตัดสินใจ")

## บริบท

- ชั้น 1 เส้นทางอนุมัติมาจาก DOA อย่างเดียว ทุก step เป็น `SEQUENTIAL` ผู้อนุมัติ 1 คน · โหมดคู่ขนานมีในโครงข้อมูลแต่ lint ปฏิเสธจนถึง S6 (§6.2 `DoaRule` · BR-DOA-08 ข้อ ค)
- ชั้น 2 มีอนุมัติคู่ขนานและแบบคณะกรรมการ (FR-WF-101 · FR-WF-102) จึงต้องมีวิธีตั้งค่า workflow

## การตัดสินใจ

> ตั้งค่า workflow ด้วยฟอร์มใน S6 และทำแบบลากวางใน S15

- S6: ฟอร์มตั้งค่า workflow + dry-run ก่อนเผยแพร่ + workflow มีเวอร์ชัน (FR-WF-103)
- S15: ตัวสร้าง workflow แบบลากวาง (FR-WF-301) · ไม่มีตัวสร้างแบบลากวางก่อน S15 (NG-4)

## ผลที่ตามมา

- ชั้น 1 ตั้งค่าผ่านหน้าจอและไฟล์ DOA (FR-DOA-001) และนำเข้าฟอร์มเป็น JSON (FR-ADM-005 AC1)
- การตั้งค่า DOA workflow และฟอร์มทำใน Workspace (เว็บและ PWA) เท่านั้น ไม่ทำใน LINE แชท LIFF หรืออีเมล (§9.1)
- S6 และ S15 ต้องเขียน sub-spec ละเอียดระดับ §7–§8 ก่อนเริ่ม (§16.2 ข้อ 7 · §16.8)
