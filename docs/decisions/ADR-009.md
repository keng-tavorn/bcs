# ADR-009: คิดราคาตามขนาดองค์กรและโมดูล ผู้ใช้ผ่าน LINE ไม่นับ seat

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: ตารางเรื่องที่ต้องตัดสินใจในเอกสารต้นทาง (spec §18.1 · ภาคผนวก C: เอกสารต้นทางหัวข้อ 14 "เรื่องที่ต้องตัดสินใจ") · เอกสารต้นทางหัวข้อ 12 การตลาดและแพ็กเกจ อยู่ที่ §4.11 และ ADR นี้ (ภาคผนวก C)

## บริบท

- BCS แบ่งเป็นเสาหลักและโมดูลที่เลือกได้ (§1.2 · §4.11)
- ผู้อนุมัติใช้ LINE และ LIFF ส่วนผู้บริหารใช้ LINE และเว็บ (§2.1)
- spec ไม่ได้บันทึกเหตุผลของรูปแบบราคานี้

## การตัดสินใจ

> คิดราคาตามขนาดองค์กรและโมดูล ผู้ใช้ผ่าน LINE ไม่นับ seat

- ระบบมีรายงานการใช้งานสำหรับคิดราคา (FR-ADM-007 · S5 · SHOULD): นับผู้ใช้หลัก (PROCUREMENT FINANCE BUDGET_ADMIN ORG_ADMIN) แยกจากผู้ใช้ผ่าน LINE รายเดือน · แสดงจำนวนข้อความ push ของ LINE รายเดือน (ชั้น 4 เพิ่ม AI credits) · PLATFORM_ADMIN ส่งออกรายงานของทุก tenant ได้

## ผลที่ตามมา

- โมดูลเปิดปิดตามสัญญาโดย PLATFORM_ADMIN (ADR-034)
- ต้องตรวจราคาแพ็กเกจ LINE ประเทศไทยล่าสุดก่อนตั้งราคาขาย (§9.3)
- โมดูล `AI` คิดตาม credits (§4.11) และบันทึก `costCredits` ต่อการเรียก (§12.2)
- ระดับราคา ช่วงขนาดองค์กร และตัวเลขราคา spec ไม่ได้ระบุ
