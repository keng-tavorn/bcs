# ADR-010: ฐานข้อมูล Neon สิงคโปร์ ตรวจ PDPA ก่อนเก็บข้อมูลจริง

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: ตารางเรื่องที่ต้องตัดสินใจในเอกสารต้นทาง (spec §18.1 · ภาคผนวก C: เอกสารต้นทางหัวข้อ 14 "เรื่องที่ต้องตัดสินใจ")

## บริบท

- ความเสี่ยง "ข้อมูลอยู่นอกประเทศ" (§18.4)
- ข้อมูลส่วนบุคคลอยู่ภายใต้ PDPA (NFR-PRIV-01 ถึง NFR-PRIV-06)

## การตัดสินใจ

> ฐานข้อมูล Neon สิงคโปร์ แต่ตรวจ PDPA และข้อกำหนดลูกค้าก่อนเก็บข้อมูลจริง

- PostgreSQL 17 บน Neon สิงคโปร์ (§5.1) · staging และ production เป็น Neon project แยกกันที่สิงคโปร์ · preview ใช้ Neon branch · local ใช้ Postgres 17 ใน docker (§4.12)
- ห้ามใช้ข้อมูลจริงจนกว่า OQ-19 (อนุมัติที่ตั้งข้อมูลตาม PDPA และข้อกำหนดลูกค้า โดย DPO หรือฝ่ายกฎหมายของลูกค้า) ปิดและมี ROPA (NFR-PRIV-01 · §18.3)

## ผลที่ตามมา

- staging ใช้ seed และข้อมูลสังเคราะห์เท่านั้นจนกว่า OQ-19 ปิด (§4.12 · §17.3) · production รอ OQ-19 (P0-05 · §16.9)
- Neon อยู่ในรายการ sub-processor พร้อมสัญญา DPA (NFR-PRIV-06)
- runtime ใช้ driver adapter ที่รองรับ interactive transaction และ `SELECT … FOR UPDATE` (ค่าเริ่มต้น `@prisma/adapter-pg`) และห้ามใช้โหมด HTTP ของ Neon กับงานที่แตะเงิน (§5.1) · `DATABASE_URL` เป็น pooled และ `DIRECT_URL` เป็น direct (ภาคผนวก B)
- ใช้ Postgres มาตรฐาน จึงย้ายไปโฮสต์ในไทยได้ (§18.4) · องค์กรมีฟิลด์ `dataRegion` (§6.2)
- hosting ต้องอยู่ภูมิภาคเดียวกับฐานข้อมูล (§5.1 · ADR-032)
