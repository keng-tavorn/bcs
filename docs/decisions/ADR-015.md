# ADR-015: เริ่มกระบวนการ ISO 27001 ก่อน S11

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: ตารางเรื่องที่ต้องตัดสินใจในเอกสารต้นทาง (spec §18.1 · ภาคผนวก C: เอกสารต้นทางหัวข้อ 14 "เรื่องที่ต้องตัดสินใจ")

## บริบท

- ความเสี่ยง "ยังไม่มีใบรับรองความปลอดภัย" ควบคุมด้วย ASVS L2 ตั้งแต่ชั้น 1 (NFR-SEC-01) และเริ่ม ISO 27001 ก่อน S11 (§18.4)
- spec ไม่ได้ระบุเหตุผลที่ผูกกับ S11

## การตัดสินใจ

> เริ่มกระบวนการ ISO 27001 ก่อน S11

- ขอบเขต ผู้รับผิดชอบ หน่วยรับรอง และวันเป้าหมาย spec ไม่ได้ระบุ
- checklist §16 ยังไม่มีข้อสำหรับงานนี้

## ผลที่ตามมา

- ควบคู่กัน ใช้ OWASP ASVS ระดับ 2 ตั้งแต่ชั้น 1 เป็นเกณฑ์ตรวจก่อน go-live (NFR-SEC-01 · §18.4) และทดสอบเจาะระบบเบื้องต้น (§16.9)
- ข้อกำหนดความปลอดภัยของชั้น 1 อยู่ใน NFR-SEC-01 ถึง NFR-SEC-11 (§13)

## อ้างอิง

spec §13 · §16.9 · §18.4 · NFR-SEC-01 ถึง NFR-SEC-11
