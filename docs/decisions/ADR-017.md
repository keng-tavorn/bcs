# ADR-017: Next.js codebase เดียว ไม่ใช้ React Native

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: การตัดสินใจของเจ้าของโปรเจกต์ (spec §18.1)

## บริบท

- BCS มีหลายประตูหน้า: Workspace · LIFF · PWA · ลิงก์ในอีเมล · Supplier Portal (§1.2 · §4.1)
- ไม่ทำแอป native และไม่ใช้ React Native (NG-3)

## การตัดสินใจ

> Next.js codebase เดียวสำหรับเว็บ LIFF PWA และ Portal ไม่ใช้ React Native

- BCS เป็น modular monolith บน Next.js โปรเจกต์เดียว (§4.1)
- route อยู่ใน `src/app`: `(workspace)` · `liff/` · `a/[token]/` · `portal/` (ชั้น 2) · `api/` (§4.10)
- Capacitor ห่อเว็บเดิมใน S15 (NG-3 · ADR-002)

## ผลที่ตามมา

- Next.js 16 App Router · React 19.2 · TypeScript strict (§5.1)
- `proxy.ts` ทำได้แค่ redirect และ header ห้ามตรวจสิทธิ์ธุรกิจ (§5.1 · §17.3) · route ที่แตะฐานข้อมูลใช้ Node runtime ห้าม Edge (§5.1)
- ทุกช่องทางเป็น adapter บาง ๆ ที่เรียก service ชุดเดียวกัน (ADR-022)
