# ADR-019: Functional core / imperative shell

- สถานะ: เสนอ
- วันที่: 2026-10-01
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- ตรรกะเงินและอำนาจ (DOA SoD งบ VAT ภาษีหัก ณ ที่จ่าย จับคู่ ไฟล์ธนาคาร เลขเอกสาร) ต้องเป็น pure function deterministic มี golden tests และ branch coverage 100% (EG-2)

## การตัดสินใจ

> Functional core / imperative shell

- `src/core` (functional core): รับ state + command + policy + เวลา แล้วคืนผลพร้อมคำอธิบาย · ห้าม I/O ทุกชนิด `Date.now()` `new Date()` แบบไม่มีอาร์กิวเมนต์ `Math.random()` `process.env` Prisma และ Next.js (§4.2 · §7.0)
- `src/server/services` (imperative shell): เปิดธุรกรรม ล็อกแถว ตรวจสิทธิ์และ SoD เรียก `decide(state, command, policy, now)` แล้วบันทึก state ledger Event และ Outbox (§4.2 · §4.3)
- core import ได้เฉพาะ `src/core/**` และ `zod` `decimal.js` `date-fns` `@date-fns/tz` (§4.10)

## ผลที่ตามมา

- บังคับด้วย ESLint boundaries และ `no-restricted-syntax` (§4.10)
- เวลาใน core มาจาก `ctx.now` ที่ inject ได้ เทสต์จึงกำหนดเวลาได้ (§4.3 · §14.4)
- branch coverage 100% ใน `src/core/{money,vat,thai,numbering,doa,sod,delegation,budget,sla,invoice,grni}` (§7.0 · NFR-MNT-02) · `resolveRoute` ต้อง deterministic (INV-DOA-02)
- PR ที่แตะ `src/core/**` ต้องมีคนอนุมัติตาม CODEOWNERS (§15.8) · ห้ามเพิ่ม dependency ใน core นอก allowlist (§17.3)
