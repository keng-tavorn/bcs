# ADR-021: งบเป็น bucket ledger ที่มี projection

- สถานะ: เสนอ
- วันที่: 2026-10-01
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- คำขอเกินงบต้องไม่หลุดถึงผู้อนุมัติ (G-4 · BR-BUD-02)
- งบมีวงจร จอง – ถือ – ตัด – คืน และต้องจองพร้อมกันได้โดยไม่เกินงบ (§7.7 · INV-BUD-05)

## การตัดสินใจ

> งบเป็น bucket ledger ที่มี projection

- งบแต่ละบรรทัดแบ่งเป็น bucket `OUTSIDE` `AVAILABLE` `RESERVED` `COMMITTED` `ACTUAL` · ทุกการเคลื่อนไหวคือรายการ `BudgetLedgerEntry` ที่ย้ายยอดจาก bucket หนึ่งไปอีก bucket (§6.2 · §7.7)
- `BudgetLineBalance` เป็นเพียง projection ที่อัปเดตในธุรกรรมเดียวกับ ledger (§6.2 · §7.7)

## ผลที่ตามมา

- ledger เป็นแหล่งความจริง ห้ามแก้ยอดใน balance โดยไม่มีรายการ ledger คู่กัน (BR-BUD-01)
- ต่อบรรทัดงบ available + reserved + committed + actual = ยอดที่นำเข้าสุทธิเสมอ (ไม่นับ OUTSIDE) (INV-BUD-01) · ไม่มี bucket ติดลบ ทั้ง CHECK ในฐานข้อมูลและใน core (INV-BUD-02 · §6.3) · ledger ทุกแถวอ้าง Event ในธุรกรรมเดียวกัน (INV-BUD-04)
- ล็อก `BudgetLineBalance` ด้วย `SELECT … FOR UPDATE` ตามลำดับ id (INV-BUD-05) · แก้ไขด้วยรายการย้อนกลับเท่านั้น (INV-BUD-06 · ADR-020)
- property test สุ่มลำดับ operation หลายพันชุด แล้วตรวจ INV-BUD-01 ถึง INV-BUD-03 (§7.7 · §15.4)
