# ADR-023: Zod เป็น schema เดียวของฟอร์ม API และ AI

- สถานะ: เสนอ
- วันที่: 2026-10-01
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- ข้อมูลชุดเดียวกันถูกตรวจหลายที่: ฟอร์มฝั่ง client · server · API · และ (ชั้น 4) ผลของ AI (§5.1)

## การตัดสินใจ

> Zod เป็น schema เดียวของฟอร์ม API และ AI

- React Hook Form + Zod v4 · schema เดียวใช้ทั้ง client server API และ (ชั้น 4) JSON schema ให้ AI ผ่าน `z.toJSONSchema` (§5.1)
- `runCommand()` ตรวจ input ด้วย Zod ไม่ผ่าน → `VALIDATION_FAILED` (§4.3)

## ผลที่ตามมา

- `Organization.settings` ต้องผ่าน `OrgSettingsSchema` ทุกครั้งที่บันทึก (§6.2 · FR-PLT-001 AC2) · `.env` ตรวจด้วย Zod ใน `src/lib/env.ts` (ภาคผนวก B)
- OpenAPI ของ `/api/v1` สร้างจาก Zod schema ชุดเดียวกับ service (§14.3)
- AI ใช้ structured outputs กับ JSON schema ที่สร้างจาก Zod ชุดเดียวกับฟอร์ม (BR-AI-10)
- `zod` อยู่ใน allowlist ของ `src/core` (§4.10)
