# ADR-025: ตัวแทนบริการภายนอกบนเครื่อง

- สถานะ: เสนอ
- วันที่: 2026-10-01 (เพิ่มหมายเหตุ 2026-10-02)
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- ส่วนที่ไม่ต้องรอใครให้ทำก่อน (§16.2 ข้อ 3) แต่บริการภายนอก เช่น Neon ที่เก็บไฟล์ ผู้ให้บริการอีเมล Inngest และ LINE ยังไม่พร้อมหรือยังไม่ตัดสิน (P0-04 ถึง P0-08 · ADR-031 ถึง ADR-033)

## การตัดสินใจ

> ใช้ตัวแทนบนเครื่อง (Postgres RustFS Mailpit Inngest dev) เพื่อไม่ต้องรอบริการภายนอก — RustFS แทน MinIO ตาม ADR-036

- `docker-compose.yml` มี `postgres:17` (สคริปต์ init สร้าง role `bcs_migrator` และ `bcs_app`) · `storage` (image `rustfs/rustfs:1.0.0` แทน MinIO ตาม ADR-036 · สร้าง bucket `bcs-local` ด้วย `scripts/storage-init.ts`) · `mailpit` (SMTP 1025 · UI 8025) · Inngest Dev Server (§5.3)
- LINE บนเครื่องใช้ `pnpm line:simulate` ส่ง webhook ปลอมที่เซ็นด้วย channel secret ใน `.env` · ใช้ tunnel สาธารณะเฉพาะตอนทดสอบกับ LINE จริง (§5.3)
- adapter ตรวจผู้ขายใช้โหมด `stub` บนเครื่อง ในเทสต์ และใน demo (BR-SUP-05 · FR-SUP-001 AC3)

## ผลที่ตามมา

- เริ่มโปรเจกต์ได้ด้วยคำสั่งเดียว (§5.3) · ค่าใน `.env.example` ชี้ไปที่ตัวแทนบนเครื่อง (ภาคผนวก B)
- S1-02 เสร็จเมื่อ `docker compose up -d` แล้ว `pnpm verify` ด่าน env ผ่าน
- integration test ใช้ Postgres จริงผ่าน docker compose (ADR-027) · `pnpm db:reset` ใช้ได้เฉพาะ `APP_ENV=local` (§5.4 · FR-PLT-007 AC2)

## หมายเหตุ (2026-10-02)

- ตัวแทน S3 บนเครื่องเปลี่ยนจาก MinIO เป็น RustFS 1.0 (สำรอง bitnamilegacy/minio) เพราะ image ทางการของ MinIO ถูกลบแล้ว ผู้ใช้ตัดสินตาม ADR-036 ซึ่งเก็บรายละเอียดและหลักฐาน · ตัวแทนอื่นในข้อนี้ไม่เปลี่ยน
