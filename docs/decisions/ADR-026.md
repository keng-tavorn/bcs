# ADR-026: next-intl ภาษาไทยเป็นค่าเริ่มต้น

- สถานะ: เสนอ
- วันที่: 2026-10-01
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- ผู้ใช้หลักใช้ภาษาไทย ภาษาอังกฤษเป็นรอง (A-08)

## การตัดสินใจ

> next-intl โดยภาษาไทยเป็นค่าเริ่มต้น

- ใช้ next-intl ไทยเป็นค่าเริ่มต้น อังกฤษรอง และทุกข้อความผ่าน next-intl (§5.1 · NFR-I18N-01)
- สลับไทยและอังกฤษได้ ข้อความทั้งหมดมาจากไฟล์แปล และ lint ห้ามข้อความฝังในคอมโพเนนต์ (FR-PLT-002 AC2) · ไฟล์แปลคือ `messages/th.json` และ `messages/en.json` (§14.4)

## ผลที่ตามมา

- วันที่เป็น พ.ศ. เวลาไทย รูปแบบเงินไทย และเรียงชื่อไทยด้วย `Intl.Collator('th')` (NFR-I18N-02) · เก็บเวลาเป็น UTC แล้วแสดงผล Asia/Bangkok (§5.1)
- แม่แบบแจ้งเตือนมีทั้งไทยและอังกฤษ (§4.7) · ข้อความ error มีแม่แบบภาษาไทย (§14.2)
- ทุกงานต้องมีข้อความ UI ทั้งไทยและอังกฤษก่อนติ๊กเสร็จ (§17.5)
