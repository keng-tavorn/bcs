# ADR-027: Vitest fast-check Playwright และ Postgres จริง

- สถานะ: เสนอ
- วันที่: 2026-10-01
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- ตรรกะเงินและอำนาจต้องมี golden tests ครบ (EG-2) · ตรวจทุกอย่างด้วยคำสั่งเดียว `pnpm verify` (EG-7)
- ความเสี่ยง "โค้ดที่ AI เขียนมีบั๊กเงียบในส่วนเงินและสิทธิ์" (§18.4)

## การตัดสินใจ

> Vitest fast-check Playwright และทดสอบกับ Postgres จริง

- unit · golden · integration · generated ใช้ Vitest · property ใช้ fast-check · e2e ใช้ Playwright · a11y ใช้ axe + Playwright (§15.1)
- integration ทดสอบ service ธุรกรรม trigger grant และ concurrency กับ Postgres จริงผ่าน docker compose (§5.1 · §15.1)

## ผลที่ตามมา

- ห้าม mock ฐานข้อมูลในเทสต์ที่ตรวจธุรกรรม (§5.1 · §17.3)
- golden runner ค้นหาไฟล์และนับเคสเอง ชื่อเทสต์มี id ของเคส และห้ามแก้ค่า expect (§7.0 · §15.2)
- ชื่อเทสต์มีแท็ก `[FR-xxx-nnn/ACn]` หรือ `[GC-…]` (§15.7)
- concurrency test กับ Postgres จริง: GC-BUD-07 · INV-NUM-01 · INV-PLT-01 · INV-TOK-01 (§15.4) · coverage ตาม NFR-MNT-02
