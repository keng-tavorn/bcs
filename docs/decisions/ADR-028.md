# ADR-028: id เป็น UUID v7

- สถานะ: เสนอ
- วันที่: 2026-10-01
- ที่มา: เสนอโดย spec · ใช้ได้ทันทีเว้นแต่มีผู้คัดค้านใน PR (§18.1)

## บริบท

- §6.1 กำหนดกติการ่วมของทุกตาราง รวมถึงรูปแบบ primary key · ฟิลด์ `id` ของ `Event` เป็น uuid v7 (§4.5)

## การตัดสินใจ

> id เป็น UUID v7

- primary key: `id String @id @default(uuid(7)) @db.Uuid` (§6.1)
- ในโค้ดสร้าง id ด้วย `newId()` (uuid v7) (§14.4) ทำในข้อ S1-04

## ผลที่ตามมา

- ลำดับรวมทั้งระบบของ Event ใช้ `seq` (bigint identity) สำหรับเรียงและ seal (§4.5)
- helper สร้าง id อยู่ใน `src/lib` (ids) ตามโครงสร้างโฟลเดอร์ (§4.10)
