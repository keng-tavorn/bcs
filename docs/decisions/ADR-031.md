# ADR-031: ผู้ให้บริการอีเมล

- สถานะ: ยังไม่ตัดสิน
- วันที่: 2026-10-01 (เพิ่มหมายเหตุ 2026-10-02)
- ที่มา: ยังไม่ตัดสินใน spec · ระหว่างรอใช้ค่าชั่วคราวที่ระบุ (§18.1)

## บริบท

- อีเมลเป็นช่องทางสำรองของ LINE เสมอ · แม่แบบอีเมล: งานอนุมัติ (สำรอง) · ผลการอนุมัติ · PO ถึงผู้ขาย (แนบ PDF) · รายงานตามรอบ · ความปลอดภัย (§9.6)
- อีเมลตีกลับรับผ่าน webhook ของผู้ให้บริการ แล้วตั้ง Notification เป็น `FAILED` (§9.6)

## การตัดสินใจ

> ผู้ให้บริการอีเมล (Resend · Amazon SES · SMTP ของลูกค้า) — ชั่วคราวใช้ adapter SMTP และ Mailpit บนเครื่อง ต้องเลือกก่อน S4

- โค้ดส่งผ่าน adapter `EmailProvider` · local ใช้ Mailpit (SMTP) (§5.1) · เลือกผู้ให้บริการด้วย `EMAIL_PROVIDER=smtp | resend | ses` (ภาคผนวก B)

## ผลที่ตามมา

- ส่งจาก `settings.email.fromAddress` ที่ตั้ง SPF DKIM DMARC ถูกต้อง (§9.6) · ค่าเริ่มต้น OQ-22: ส่ง PO จากโดเมน BCS พร้อม reply-to จัดซื้อ จนกว่าจะตั้งโดเมนลูกค้า
- FR-NOTI-002 AC3 ตรวจ SPF และ DKIM ใน S4 · ก่อน go-live โดเมนอีเมลต้องผ่าน SPF และ DKIM (§16.9)
- demo ส่งเข้า inbox demo ที่ BCS ควบคุม (§16.10) · P0-08 `[คน]` เลือก inbox อีเมลสำหรับ demo · S4-06 ใช้ Mailpit หรือ inbox ของ BCS
- ผู้ให้บริการอีเมลอยู่ในรายการ sub-processor พร้อมสัญญา DPA (NFR-PRIV-06)

## หมายเหตุ (2026-10-02)

- ผู้ใช้ยังไม่ได้เลือกผู้ให้บริการอีเมลของ staging ข้อนี้จึงยังเป็น "ยังไม่ตัดสิน"
