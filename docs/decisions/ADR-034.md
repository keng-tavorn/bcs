# ADR-034: PLATFORM_ADMIN เปิดปิดโมดูลตามสัญญา

- สถานะ: ตัดสินแล้ว
- วันที่: 2026-10-01
- ที่มา: การตัดสินใจของเจ้าของโปรเจกต์ (spec §18.1)

## บริบท

- BCS ครบวงจรแต่เปิดใช้ทีละเสา (P-9) · โมดูลเสริมเลือกได้ตามสัญญา (§1.2 · §4.11) และคิดราคาตามโมดูล (ADR-009)

## การตัดสินใจ

> PLATFORM_ADMIN เปิดปิดโมดูลตามสัญญา ต้องมี contractRef และเหตุผล และแจ้ง ORG_ADMIN ส่วน ORG_ADMIN ดูอย่างเดียว

- เปิดปิดได้เฉพาะ PLATFORM_ADMIN ที่ `/platform/tenants/[orgId]/modules` โดยไม่ต้อง break-glass เพราะไม่อ่านข้อมูลธุรกิจ · ORG_ADMIN ดูได้อย่างเดียวที่ `/admin/modules` (§2.2 · §4.11 · BR-AUTH-08)
- กติกา §4.11: (1) ทุกครั้งต้องมี `contractRef` และเหตุผล (2) เปิดได้เมื่อโมดูลที่ต้องมีเปิดอยู่แล้ว (3) ปิดไม่ได้ถ้ามีโมดูลที่เปิดอยู่พึ่งพา (4) ปิดขณะมีเอกสารค้าง → `MODULE_IN_USE` (OQ-33) (5) ทุกการเปลี่ยนสร้าง event `organization.module_enabled` หรือ `organization.module_disabled` และแจ้ง ORG_ADMIN ทันที (6) การปิดไม่ลบข้อมูล แค่ซ่อนเมนูและปฏิเสธ command

## ผลที่ตามมา

- ทุก service ของโมดูลเสริมเรียก `requireModule(ctx, '<MODULE>')` ถ้าปิดอยู่ → `MODULE_DISABLED` (§4.11 · FR-PLT-011) · `CORE` เปิดเสมอ
- capability `platform.modules.manage` และ `admin.modules.view` (§2.4) · ตาราง `OrgModule` เก็บ contractRef reason และ changedByPlatformAdminId (§6.2) · event มี actorType `PLATFORM_ADMIN` (BR-AUTH-08)
- ประวัติการเปลี่ยนโมดูลอยู่ในรายงานประวัติการเปลี่ยนนโยบาย (FR-DOA-011) · การเปลี่ยนโมดูลไม่ต้อง deploy (EG-8)
- ทำในข้อ S1-12 (FR-ADM-006 AC1 · FR-PLT-011)
