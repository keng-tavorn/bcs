# ADR-037: ข้อความหน้าจอแยกไฟล์ตาม namespace

- สถานะ: เสนอ
- วันที่: 2026-10-02
- ที่มา: ตัดสินระหว่าง S1-01 เพื่อให้งานหน้าจอหลายส่วนทำพร้อมกันได้โดยไม่แก้ไฟล์เดียวกัน

## บริบท

- ข้อความหน้าจออยู่ใน `messages/th.json` และ `messages/en.json` (§14.4 · ADR-026) และต้องมีครบทั้งไทยและอังกฤษ (§17.5)
- งานหน้าจอแต่ละส่วน (เข้าสู่ระบบ คำขอ PO งบ …) เพิ่มข้อความพร้อมกัน ถ้าทุกคนแก้ไฟล์เดียวกันจะชนกันบ่อยและตรวจยากว่า key ไทยกับอังกฤษครบคู่

## การตัดสินใจ

> ข้อความหน้าจอแยกไฟล์ตาม namespace ใน `messages/src/{th,en}/` แล้วสร้าง `messages/th.json` และ `messages/en.json` ด้วยสคริปต์

- หนึ่งไฟล์ต่อ namespace เช่น `messages/src/th/auth.json` และ `messages/src/en/auth.json` · ชื่อไฟล์คือ namespace บนสุดที่โค้ดเรียก (`useTranslations('auth.login')`)
- `node scripts/build-messages.mjs` รวมเป็น `messages/th.json` และ `messages/en.json` (เรียง key) และรันอัตโนมัติก่อน `pnpm dev` `pnpm build` และ `pnpm typecheck`
- `--check` ล้มเมื่อไฟล์ที่สร้างไม่ตรงกับต้นฉบับ หรือ key ของไทยกับอังกฤษไม่ครบคู่ · ด่าน messages ของ `pnpm verify` ใช้โหมดนี้

## ผลที่ตามมา

- แก้ข้อความที่ `messages/src/` เท่านั้น · ไฟล์ `messages/th.json` และ `messages/en.json` เป็นผลลัพธ์ที่ commit ไว้ให้ next-intl อ่าน
- ข้อความที่ผู้ใช้เห็นทั้งหมดห้ามฝังในโค้ด (FR-PLT-002 AC2) · lint ตรวจใน `src/app` และ `src/ui`

## อ้างอิง

spec §14.4 · §17.5 · FR-PLT-002 · ADR-026
