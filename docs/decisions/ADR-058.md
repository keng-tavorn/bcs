# ADR-058: หน้าตา Workspace ใกล้ Zip ในโทนเขียว ไม่มี pop-up ที่เด้งเอง

- สถานะ: ตัดสินแล้ว (ผู้ใช้ 2026-10-08)
- วันที่: 2026-10-08
- ที่มา: ผู้ใช้สรุปเดโม Intake-to-Procure ของ Zip (7 ต.ค. 2026) และตัดสิน 2026-10-08 · spec 0.3 §8.13 §9.10

## บริบท

- หน้าจอของเส้นชัย A ใช้ได้ แต่ผู้ใช้เห็นว่าเดโมของ Zip ใช้ง่ายกว่า: เริ่มคำขอเร็ว เห็นงานของตัวเองทันที และตัดสินในจอเดียว
- ลูกค้ารายแรกใช้ LINE เป็นหลักบนมือถือ Workspace จึงต้องเรียบและเร็วบนคอม
- ห้ามลอกโลโก้ สี ชื่อ ภาพ หรือข้อความของ Zip (§9.9)

## การตัดสินใจ

> หน้าตา Workspace ใกล้ Zip ในโทนเขียว: แถบเมนูซ้ายเขียวเข้มที่ยุบได้ หน้าแรกงานของฉัน (ทักทาย ⌘K chip 3 ตัว การ์ด 4 ใบ) dialog เลือกประเภท ฟอร์มทีละขั้น หน้าเอกสารแบบแท็บ และสรุปผู้บริหาร · ไม่เอา pop-up ที่เด้งเอง tour Cards RFx Surveys และ integration ของ Zip (NG-13) · token ชุดเริ่มต้นคงเดิม และเพิ่ม token ส่วนขยายใน §9.10

## ผลที่ตามมา

- ขั้น S16 ใน §16.12 ทำหน้าจอใหม่ทีละข้อ โดยไม่เปลี่ยนผลคำนวณของ `src/core` และ service ที่แตะเงิน และฉาก demo เดิมต้องผ่านบนหน้าจอใหม่
- FR ใหม่ใน §8.13: FR-PLT-013 FR-PLT-014 FR-VIS-006 FR-VIS-007 FR-INT-010 ถึง FR-INT-013
- NG-13: ไม่มี tour pop-up ขอบคุณ คลิปที่เด้งเอง ปุ่มแชทลอย เมนู Cards RFx และ Surveys
- token ส่วนขยายและคู่สีใน §9.10 ต้องผ่าน contrast ซึ่ง `pnpm spec:check` คำนวณซ้ำทุกครั้ง
