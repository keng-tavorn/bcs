# ADR-059: shadcn/ui เป็นชุดคอมโพเนนต์หลัก และไลบรารีเสริมตาม §5.5

- สถานะ: ตัดสินแล้ว (ผู้ใช้ให้เพิ่มไลบรารีได้ 2026-10-08)
- วันที่: 2026-10-08
- ที่มา: ผู้ใช้ให้เพิ่มไลบรารีได้ 2026-10-08 · spec 0.3 §5.5

## บริบท

- เส้นชัย A ใช้ shadcn/ui บางส่วนและเขียนคอมโพเนนต์เองหลายตัว หน้าจอใหม่ต้องการ Sidebar Command Dialog Drawer Chart และอื่น ๆ ใน §9.10
- การเพิ่ม dependency นอก §5.5 ต้องหยุดถาม (§17.4) จึงต้องมีรายการที่อนุมัติล่วงหน้าพร้อมขั้นที่ติดตั้ง
- หน้า LIFF มีงบ JavaScript ที่เข้ม (ADR-052) จึงห้ามดึงไลบรารีของ Workspace เข้าไป

## การตัดสินใจ

> shadcn/ui เป็นชุดคอมโพเนนต์หลักผ่าน CLI v4 ด้วย base เดียวทั้งโปรเจกต์ · ไลบรารีเสริมตาม §5.5 ติดตั้งเมื่อถึงขั้นที่ระบุโดยไม่ต้องถาม · ไม่ใช้ motion next-themes react-query และตัวแก้ข้อความแบบ rich text · หน้า LIFF คงชุดเบา (ADR-052)

## ผลที่ตามมา

- ใช้ CLI v4 ด้วย base เดียวทั้งโปรเจกต์ตามที่ `shadcn info` รายงาน · `--dry-run` ก่อนทุกครั้ง และ `--diff` กับไฟล์ที่เคยแก้
- ไลบรารีในตาราง §5.5 ติดตั้งเมื่อถึงขั้นที่ระบุโดยไม่ต้องถาม ยกเว้นแถวที่เขียนว่าต้องยืนยัน (`@better-auth/passkey`)
- lint กัน import ของ Workspace ในหน้า LIFF (S16-02 · FR-PLT-013 AC5)
- skill `shadcn` อยู่ใน `.claude/skills/` เป็นคู่มือของ agent ไม่ใช่ dependency ของแอป และ token กับรายการห้ามใน §9.9 มาก่อนเสมอ

## อ้างอิง
