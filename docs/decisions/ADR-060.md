# ADR-060: AI เรียก Claude ผ่าน AI SDK ใน src/integrations/ai

- สถานะ: เสนอ
- วันที่: 2026-10-08
- ที่มา: เสนอโดย spec 0.3 (2026-10-08) · ใช้เมื่อถึง S13 เว้นแต่ผู้ใช้คัดค้าน

## บริบท

- S13 (เส้นชัย F) ต้องมี agent ของระยะ 1 และหน้าจอแชทแบบ stream
- AI อยู่ในโมดูล `AI` เท่านั้น และทุกโมดูลต้องทำงานได้เมื่อปิด AI (EG-1 · NG-5 · §12)
- structured outputs ต้องมาจาก Zod (BR-AI-10)

## การตัดสินใจ

> AI เรียก Claude ผ่าน AI SDK (`ai` `@ai-sdk/anthropic` `@ai-sdk/react`) ใน `src/integrations/ai` · หน้าจอแชทใช้ Message Bubble Marker ของ shadcn/ui และทดสอบด้วย `@shadcn/helpers` โดยไม่ใช้ key · ถ้าต้องใช้ความสามารถที่ AI SDK ยังไม่รองรับ ใช้ `@anthropic-ai/sdk` ใน adapter เดียวกันพร้อม ADR

## ผลที่ตามมา

- ยังไม่ติดตั้งจนถึง S13 (`AI_ENABLED=false`) · ตรวจเวอร์ชันและเอกสารอีกครั้งตอนเริ่ม S13
- เทสต์หน้าจอ AI ใช้ `@shadcn/helpers` จำลองบทสนทนา จึงไม่ต้องใช้ key ใน CI
- ถ้าต้องใช้ความสามารถที่ AI SDK ยังไม่รองรับ ใช้ `@anthropic-ai/sdk` ใน adapter เดียวกันพร้อม ADR ใหม่

## อ้างอิง

- spec §5.5 · §12 · BR-AI-10 · P-3
