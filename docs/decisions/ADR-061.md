# ADR-061: BCS Go ใช้ Capacitor 8 ห่อเว็บเดิม

- สถานะ: เสนอ
- วันที่: 2026-10-08
- ที่มา: เสนอโดย spec 0.3 (2026-10-08) · ใช้เมื่อถึง S17 เว้นแต่ผู้ใช้คัดค้าน

## บริบท

- ADR-002 ให้มือถือเริ่มที่ PWA แล้วค่อยเป็น Capacitor · ADR-017 ใช้ Next.js codebase เดียว ไม่ใช้ React Native
- S17 (เส้นชัย G) ต้องการ push สแกน barcode biometric และตรวจรับตอนออฟไลน์

## การตัดสินใจ

> BCS Go ใช้ Capacitor 8 ห่อเว็บเดิม: push เป็นช่องทางแจ้งเตือนที่สาม · สแกน barcode ด้วย ML Kit · biometric ผ่าน passkey · ตรวจรับออฟไลน์ด้วยคิวในเครื่องที่ส่งผ่าน command เดิม · รายละเอียดตัดสินใน sub-spec S17

## ผลที่ตามมา

- ไม่มีโค้ดธุรกิจในแอป ทุกการเปลี่ยนสถานะผ่าน command เดิมของเซิร์ฟเวอร์
- push เป็นช่องทางแจ้งเตือนที่สามต่อจาก LINE และอีเมล (§4.7)
- `@better-auth/passkey` แตะ auth จึงต้องให้ผู้ใช้ยืนยันก่อนติดตั้ง (§5.5 · §17.4)
- รายละเอียดตัดสินใน sub-spec S17 ที่ผู้ใช้อนุมัติก่อนเขียนโค้ด

## อ้างอิง

- spec §5.5 · §16.8 · ADR-002 · ADR-017 · NEW-53
