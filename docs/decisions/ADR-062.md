# ADR-062: ทำงานทีละข้อ บอก effort ถัดไป และแยกการตรวจจากการสร้าง

- สถานะ: ตัดสินแล้ว (ผู้ใช้ขอให้ซอยงานและบอก effort 2026-10-08)
- วันที่: 2026-10-08
- ที่มา: ผู้ใช้ขอให้ซอยงานและบอก effort 2026-10-08 · spec 0.3.1 §17.9 · CLAUDE.md หัวข้อ 13

## บริบท

- รอบ "ทำจนถึงเส้นชัย A" ใช้ ultracode และ effort `max` ทำให้ช้าและกิน token มาก
- ผู้ใช้ไม่ใช่โปรแกรมเมอร์และกดตามคำแนะนำของ agent จึงต้องได้คำสั่งถัดไปที่ชัดเจน
- context ที่ยาวทำให้ผลแย่ลงและทุกข้อความแพงขึ้น และการรีวิวที่ได้ผลคือให้ตัวตรวจที่ไม่ได้เขียนโค้ดเป็นผู้ตรวจ

## การตัดสินใจ

> ทำงานทีละข้อ: คำสั่ง "ทำข้อถัดไป" = 1 ข้อใน 1 แชต ติ๊กและ commit ทุกข้อ แล้วบอกคำสั่งถัดไปกับ effort · effort ตาม §17.9 (Claude Opus 5.5 เริ่มที่ `medium` · `high` กับข้อที่แตะเงิน สิทธิ์ หรือการอนุมัติ · ไม่ใช้ `max` และ ultracode เป็นค่าประจำ) · การตรวจแยกจากการสร้างด้วย `/code-review` ในบริบทใหม่ และรีวิวโค้ดทั้งรอบก่อนรายงานเส้นชัย · อ่าน spec เฉพาะส่วนตาม §0.4

## ผลที่ตามมา

- 1 ข้อต่อ 1 แชต ติ๊กและ commit ทุกข้อ (push เมื่อมี remote) แล้วจบด้วยบรรทัด "ถัดไป:" ที่บอกคำสั่งและ effort
- ข้อที่แตะเงิน สิทธิ์ หรือการอนุมัติ มีบรรทัด "ตรวจก่อน:" ให้ผู้ใช้รัน `/code-review high` ในบริบทใหม่ และ S16-12 รีวิวโค้ดทั้งรอบตั้งแต่ tag `a2-start`
- แถว "ทุก session" ใน §0.4 อ่านน้อยลง · `pnpm spec:check` ตรวจว่า CLAUDE.md มีกติกา §17.9 ครบ (S16-01)
