# ADR-063: shadcn/ui ใช้ base Radix และฐานดีไซน์ของ S16-02

- สถานะ: ตัดสินแล้ว (agent ตัดสินตาม §5.5 และ §9.10 ระหว่าง S16-02)
- วันที่: 2026-10-09
- ที่มา: S16-02 · spec §5.5 · §9.9 · §9.10 · FR-PLT-013 AC1 AC5 · ADR-052 ADR-059

## บริบท

- `pnpm dlx shadcn@latest info` รายงานว่าโปรเจกต์ยังไม่มี `components.json` และยังไม่มีคอมโพเนนต์ แต่ `package.json` มี `radix-ui` อยู่แล้ว · §5.5 ห้ามปน Radix กับ Base UI
- `shadcn init` เขียนทับ token ใน `globals.css` ด้วยสีเทาของ shadcn และเปลี่ยนฟอนต์เป็น Geist ซึ่งผิด §9.9
- ใน registry ของ base Radix: `combobox` ดึง `@base-ui/react` มาด้วย · `toast` มีเฉพาะ Base UI · `sonner` ดึง `next-themes` (§5.5 ห้าม) · คอมโพเนนต์แชท (Attachment Message Bubble Marker) import `cn` จากแพ็กเกจ npm ชื่อ `cn`

## การตัดสินใจ

> ใช้ base Radix (style `radix-nova`) ทั้งโปรเจกต์ · คอมโพเนนต์อยู่ใน `src/ui/shadcn` และใช้ `cn` ของ `src/ui/cn.ts` · token และการจับคู่ตัวแปรของ shadcn/ui อยู่ใน `src/app/globals.css` ตาม §9.10 (ไม่ใช้ theme ที่ CLI สร้าง) · Combobox ประกอบจาก Popover กับ Command · ข้อความแจ้งผลใช้ Sonner โดยตัด `next-themes` · ค่าสีที่ CSS เข้าไม่ถึงอยู่ใน `src/ui/theme.ts` ไฟล์เดียว

## ผลที่ตามมา

- `components.json`: aliases `ui` = `@/ui/shadcn` · `utils` = `@/ui/cn` · `hooks` = `@/ui/hooks` · เพิ่มคอมโพเนนต์ด้วย `pnpm dlx shadcn@latest add <ชื่อ> --dry-run` ก่อนทุกครั้ง แล้วตรวจว่าไม่มี `@base-ui/react` `next-themes` หรือ `cn` (แพ็กเกจ) ติดมา
- ปรับคอมโพเนนต์หลังติดตั้งตาม §9.10: `text-xs` เป็น `text-sm` (ไม่ต่ำกว่า 14 px) · วง focus ทึบ 2 px ห่างขอบ 2 px · Card ใช้ขอบ `--line` ไม่มีเงา · Badge มีสี ok warn danger info neutral · พื้นหลัง overlay ใช้ `bg-ink/30` ไม่มี blur · Drawer (vaul) ไม่เกิน 200 ms · ปิด animation เมื่อ `prefers-reduced-motion` · ข้อความใน sr-only และ aria-label มาจาก namespace `ui` ของ next-intl
- `--radius` 8 px: `rounded-md` และ `rounded-lg` เป็น 8 px ทั้งคู่ เพราะคอมโพเนนต์ของ shadcn/ui วาดการ์ด ปุ่ม และช่องกรอกด้วย `rounded-lg` และหน้าจอเดิมใช้ `rounded-md`
- `--accent` เปลี่ยนจาก `--surface` เป็น `--primary-tint` และ `--input` จาก `--ink-muted` เป็น `--line-strong` ตามตารางของ §9.10: พื้นแถวที่ชี้และขอบช่องกรอกของหน้าจอเดิมเปลี่ยนสีตาม
- lint ใหม่: `bcs/no-color-literal` (ห้ามสี hex ฟังก์ชันสี และสี palette ของ Tailwind ใน `src/app` และ `src/ui` นอก `src/ui/theme.ts`) · `bcs/liff-imports` (หน้า LIFF ห้าม import ไลบรารีของ Workspace คอมโพเนนต์ `src/ui/shadcn` และ `tailwind-merge` · รายการเดียวกับที่เทสต์ไล่ import ใช้ อยู่ใน `eslint/liff-forbidden.mjs`)
- Sonner ไม่อยู่ในตาราง §5.5 แต่เป็นคอมโพเนนต์ที่แถว "ข้อความแจ้งผล" ของ §9.10 ใช้ได้เมื่อไม่มี Toast และไม่แตะ auth crypto หรือเงิน
