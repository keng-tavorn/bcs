# ADR-103: แสดงเส้นทางคู่ขนานเป็นการ์ดตราประทับที่จัดกลุ่ม

- สถานะ: เสนอ (ร่าง P1-04 · รอผู้ใช้อนุมัติใน P1-06)
- วันที่: 2026-10-11
- ที่มา: docs/sub-specs/S6.md หัวข้อ "หน้าจอ" · ข้อ P1-04

## บริบท

- ขั้นคู่ขนานต้องแสดงบนเว็บ LIFF และการ์ด LINE · หน้า LIFF ใช้ชุดเบาและมีงบ JavaScript (ADR-052)
- ตาราง §5.5 มีไลบรารีกราฟให้เลือกได้แต่ต้องติดตั้งเพิ่ม

## การตัดสินใจ

> เส้นทางคู่ขนานแสดงเป็นการ์ดตราประทับแนวตั้งที่จัดกลุ่ม slot ด้วยคอมโพเนนต์ shadcn/ui · ไม่ติดตั้ง `@xyflow/react` เพราะขั้นคู่ขนานแสดงเป็นกลุ่มได้โดยไม่ต้องใช้กราฟ และใช้ร่วมกับ LIFF ชุดเบาได้ (ADR-052)

## ผลที่ตามมา

- ใช้คอมโพเนนต์ shadcn/ui ที่มีอยู่ ไม่เพิ่ม dependency · แสดง "ได้ x จาก y" ต่อกลุ่ม
- หน้าจอเดียวกันใช้ได้ทั้ง Workspace และ LIFF โดยไม่ละเมิดงบ JavaScript
