# ADR-104: ledger ย้ายไป OUTSIDE ได้เฉพาะโอน ปรับ และคืนเกินงบ

- สถานะ: เสนอ (ร่าง P1-04 · รอผู้ใช้อนุมัติใน P1-06)
- วันที่: 2026-10-11
- ที่มา: docs/sub-specs/S6.md หัวข้อ "กฎ" (BR-BUD-09 BR-BUD-18 INV-BUD-07) · ข้อ P1-04

## บริบท

- ledger ชั้น 1 ไม่มีทางย้ายเงินออกจากบรรทัดงบนอกจากใช้จ่าย (`Movement.to` ไม่มี OUTSIDE) และ INV-BUD-01 นับเฉพาะยอดนำเข้า
- FR-BUD-103 ต้องโอนและปรับงบ และ FR-BUD-101 ต้องเติมงบเมื่ออนุมัติเกินงบแล้วคืนส่วนที่ไม่ใช้
- `plannedSatang` ถูก service และสรุปรายวันใช้เป็นยอดตั้งของบรรทัด

## การตัดสินใจ

> ledger ย้ายไป OUTSIDE ได้เฉพาะการโอนออก ปรับลด และคืนส่วนเกินงบ (ตอนใช้ ตอนหมดอายุ และหลังใช้) · `plannedSatang` คงความหมายยอดตั้งสุทธิที่ service ใช้อยู่และเป็นตัวหารของ % ใช้แล้ว · งบตั้งต้นคำนวณจาก ledger ของการนำเข้า · event ของ ledger เลือกตามบัคเก็ตต้นทาง ปลายทาง และชนิดเอกสาร

## ผลที่ตามมา

- sourceType ที่ไป OUTSIDE ได้มีสองชนิดเท่านั้น (`BUDGET_TRANSFER` `BUDGET_OVERRUN`) · op เดิมไม่เปลี่ยนผล (GC-BUD-01 ถึง 07)
- ถ้อยคำ INV-BUD-01 และตัวหารของ % ใช้แล้วใน §11.2 ต้องแก้ตามที่ผู้ใช้อนุมัติใน P1-06 (OQ-105)
- property test เพิ่ม op โอน ปรับ เกินงบ และคืนหลังใช้
