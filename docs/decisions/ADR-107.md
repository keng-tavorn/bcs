# ADR-107: ตรวจคำขอซ้ำและแตกยอดด้วย pure function และธงที่ไม่บล็อก

- สถานะ: เสนอ (ร่าง P1-04 · รอผู้ใช้อนุมัติใน P1-06)
- วันที่: 2026-10-11
- ที่มา: docs/sub-specs/S6.md หัวข้อ "กฎ" (BR-DUP-01 ถึง BR-DUP-05) · ข้อ P1-04

## บริบท

- FR-INT-103 ต้องจับคำขอซ้ำและการแตกยอดเลี่ยงวงเงิน แต่การบล็อกหรือเปลี่ยนเส้นทางจากการเดาคือการเปลี่ยนอำนาจอนุมัติ (OQ-103)

## การตัดสินใจ

> ตรวจคำขอซ้ำและแตกยอดด้วย pure function ใน `src/core` บนกุญแจบรรทัดที่ normalize · เก็บผลเป็น `RequestFlag` ต่อการส่งแบบ append-only · ธงไม่บล็อกและไม่เปลี่ยนเส้นทาง

## ผลที่ตามมา

- กุญแจบรรทัด normalize ด้วย NFC trim ยุบช่องว่างและตัวพิมพ์เล็ก · ผลเก็บใน `RequestFlag` append-only ต่อการส่ง
- ธงแสดงต่อผู้อนุมัติ รายงาน และสรุปของ AUDITOR · DUPLICATE ต้องกรอกเหตุผลทั้งบนเว็บและ LIFF
- golden GC-DUP-01 ถึง 13
