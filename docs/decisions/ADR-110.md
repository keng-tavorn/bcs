# ADR-110: ชุดค่าตั้งนำเข้าเป็นร่างและ sandbox ตั้งต้นแบบ tenant ใหม่

- สถานะ: เสนอ (ร่าง P1-04 · รอผู้ใช้อนุมัติใน P1-06)
- วันที่: 2026-10-11
- ที่มา: docs/sub-specs/S6.md หัวข้อ "กฎ" (BR-UAT-01 ถึง BR-UAT-04) · ข้อ P1-04

## บริบท

- FR-PLT-101 ต้องมี UAT ให้ลูกค้าลองค่าตั้งก่อนใช้จริง · NG-12 ห้าม BCS สร้างหรือเผยแพร่ DOA และโครงสร้างอำนาจของลูกค้า · EG-8
- production ยังไม่ตัดสิน (ADR-032) และสายห้าม deploy หรือแก้ staging

## การตัดสินใจ

> ชุดค่าตั้ง (`ConfigPackage`) เป็น JSON มี schemaVersion และ sha256 · นำเข้าสร้างเฉพาะร่างที่ต้องอนุมัติตามเส้นทางปกติ ไม่เผยแพร่เองและไม่มีข้อมูลธุรกิจ (NG-12 EG-8) · sandbox ตั้งต้นแบบ tenant ใหม่โดยคนของลูกค้า

## ผลที่ตามมา

- ชุดค่าตั้งเป็น JSON มี schemaVersion และ sha256 ไม่มีคำขอ งบ เลขบัญชี หรือข้อมูลส่วนบุคคล · นำเข้าสร้างเฉพาะร่างที่ต้องอนุมัติตามเส้นทางปกติ
- PLATFORM_ADMIN สร้าง sandbox พร้อม contractRef เท่านั้น · ลูกค้าตั้งต้นผังและ DOA เองผ่าน BR-DOA-19 · ชั้น demo ใช้ `SIMEC-UAT` บนเครื่อง
- UAT บน hosting ของ production เป็นงาน `[คน]` หลังตัดสิน ADR-032 (S6-24)
