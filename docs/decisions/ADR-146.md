# ADR-146: เอกสารสังเคราะห์ของชุดประเมิน AI

- สถานะ: ยอมรับ (ร่าง P1-04 · ผู้ใช้อนุมัติตามที่แนะนำใน P1-06 เมื่อ 2026-10-12)
- วันที่: 2026-10-11
- ที่มา: docs/sub-specs/S13.md หัวข้อ "ชุดประเมิน" และ "การอ่านชีตของไฟล์ระยะ 1" · ข้อ P1-04

## บริบท

- ชุดประเมินชั้น demo ใช้ข้อมูลสังเคราะห์ (OQ-19) · ชีต DocSamples มีคำตอบที่ถูก 57 ฉบับแต่ยังไม่มีไฟล์เอกสาร และขาดเคสยาก (ผู้ขายไม่จด VAT สกุลเงินอื่น ตัวเลขไทย หลายบรรทัด)
- ตัวตรวจ `validate_inputs.py` คิด VAT 7% ทุกฉบับและไม่มีคอลัมน์สกุลเงิน · ไฟล์ xlsx ระยะ 1 ถูกสร้างใหม่จากหลายสาย (ADR-065)
- ไฟล์ต้องเหมือนเดิมทุกครั้งที่สร้าง เพื่อให้คำตอบที่บันทึกไว้ใช้ซ้ำได้

## การตัดสินใจ

> เอกสารสังเคราะห์ของชุดประเมิน AI สร้างด้วย Playwright จากชีต DocSamples และเคสเพิ่มใน `tests/fixtures/ai-docs/cases.yaml` (HTML แม่แบบ ฟอนต์ OFL การบิดภาพด้วย CSS วันฐานคงที่) เก็บใน `tests/fixtures/ai-docs/` พร้อม manifest sha256 · ไม่แก้ไฟล์ข้อมูลระยะ 1

## ผลที่ตามมา

- เคสเพิ่มอย่างน้อย 12 ฉบับอยู่ใน `tests/fixtures/ai-docs/cases.yaml` ไม่แก้ `scripts/inputs_p1/` และไฟล์ระยะ 1 จึงไม่ชนกับสายอื่น · ยอดของเคสเพิ่มตรวจด้วยเทสต์ที่ใช้ `src/core/money`
- สคริปต์สร้างไฟล์ด้วย Playwright จาก HTML แม่แบบ ฟอนต์ OFL ในโปรเจกต์ และการบิดภาพด้วย CSS · วันที่ = วันฐานคงที่ 2026-10-01 − `docDaysAgo`
- manifest sha256 และเทสต์ว่าไฟล์ตรง manifest · ตัวให้คะแนน normalize คำตอบของ DocSamples ตาม BR-AI-26
