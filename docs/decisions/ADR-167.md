# ADR-167: หน้าแรกใน LIFF ใช้ service หน้าแรกเดิม

- สถานะ: ยอมรับ (ร่าง P1-04 · ผู้ใช้อนุมัติตามที่แนะนำใน P1-06 เมื่อ 2026-10-12)
- วันที่: 2026-10-11
- ที่มา: docs/sub-specs/S17.md หัวข้อ "กฎ" (BR-LINE-18) และ FR-LINE-302 · ข้อ P1-04

## บริบท

- §8.12 ของ FR-LINE-302 ให้หน้าแรกใน LIFF ใช้ query ชุดเดียวกับหน้าแรกเว็บ (`src/server/queries/home.ts`) และอยู่ในงบ JavaScript ของ LIFF (ADR-052)
- ค่าคงที่ `LIFF_HOME_PATH` เดิมชี้กล่องงานและถูกใช้หลายที่ เช่นหน้าช่วยเหลือ
- หน้างาน `/liff/tasks/[id]` ของขั้นผู้ตรวจและกรรมการเป็นของ S6

## การตัดสินใจ

> หน้าแรกใน LIFF `/liff/home` เรียก service หน้าแรกเดิมและ render ฝั่งเซิร์ฟเวอร์ · `/liff` พาผู้ผูกแล้วไป `/liff/home` · ค่าคงที่ `LIFF_HOME_PATH` เดิม (กล่องงาน) คงความหมายเดิม เพิ่มค่าคงที่ใหม่สำหรับหน้าแรก

## ผลที่ตามมา

- ตัวเลขในหน้าแรก LIFF เท่าหน้าแรกเว็บเสมอ รวมงานผู้ตรวจและงานกรรมการของ S6 ใน "รอฉันอนุมัติ"
- ไม่มี JavaScript ใหม่ฝั่ง client นอกจากปุ่มลองใหม่ จึงไม่เกินงบของ ADR-052
- ลิงก์เดิมที่ใช้ `LIFF_HOME_PATH` ไม่เปลี่ยนที่หมาย
