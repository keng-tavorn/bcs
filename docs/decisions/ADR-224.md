# ADR-224: ตอบด้วยหลักฐานจาก SupplierDocument ของ S7 และผู้ขายระดับสูงต้องยืนยันเอง

- สถานะ: ยอมรับ (ร่าง ADR-075 · ผู้ใช้อนุมัติตามที่แนะนำเมื่อ 2026-11-01)
- วันที่: 2026-11-01
- ที่มา: docs/sub-specs/S11.md หัวข้อ "กฎ" (BR-RSK-05 BR-RSK-06 BR-RSK-18) · §8.12 FR-RSK-201 · หัวข้อ "ให้ขั้นอื่น" ของ docs/sub-specs/S7.md ที่ขอให้ S11 ตรวจไขว้เรื่อง `scope`

## บริบท

- §8.12 FR-RSK-201: "คำถามที่ผูกกับใบรับรองบันทึกเป็น 'ตอบด้วยหลักฐาน' ไม่ลบทิ้ง ใช้ได้เมื่อใบยังไม่หมดอายุและขอบเขตครอบคลุมงานที่จ้าง · ผู้ขายระดับ HIGH ต้องตอบทุกข้อ ข้อที่ตอบด้วยหลักฐานจึงไม่นับแทนใน G-9"
- S7 ให้ `SupplierDocumentType.linkedRiskQuestionCodes` (ทิศทาง ประเภทเอกสาร → รหัสคำถาม) `SupplierDocument.scope` และ `singleInstance` (ISO 9001 กับ ISO 27001 เป็นคนละฉบับ) และ `supplierDocumentStatus(ctx, supplierId)` ที่คืนหลายแถวต่อประเภทพร้อม `scope` `expiresOn` `documentId` (ADR-185 · แก้ตามผลตรวจ SPEC-SPEC-04)
- ถ้า S11 เก็บชื่อประเภทเอกสารในคำถามเองจะมีสองแหล่งความจริง · ถ้าให้คำตอบจากหลักฐาน "แทน" คำตอบของผู้ขายทุกระดับ ผู้ขาย HIGH จะเป็น COMPLETED โดยไม่เคยยืนยันอะไร
- ผู้ขายบางรายต้องแนบเอกสารนโยบาย (PDPA ความปลอดภัย) ประกอบคำตอบ ซึ่งไม่ใช่ "ประเภทเอกสารขององค์กร" ที่มีวันหมดอายุ

## การตัดสินใจ

> คำถามที่ `SupplierDocumentType` (active) ขององค์กรอ้างใน `linkedRiskQuestionCodes` ได้คำตอบ source `EVIDENCE` อัตโนมัติ (ตัวเลือกที่ `evidence = true` ของคำถาม) จากแถว OK/EXPIRING ของ `supplierDocumentStatus` ของ S7 (= `SupplierDocument` VERIFIED ที่ `expiresOn ≥ วันนี้` ตาม Asia/Bangkok · เท่าวันยังใช้ได้) และเมื่อคำถาม `evidenceScopeRequired` ต้องมี `scope` ของแถวเท่ากับ `RiskQuestion.evidenceScope` (scope/มาตรฐานที่คำถามอ้าง เช่น "ISO 45001") **และ** เท่ากับค่าใดใน `RiskAssessment.workScopes` หลัง `normalizeScope` **ทุกฝั่ง** ด้วยกติกาเดียวกับ BR-SDOC-03 ของ S7 ทุกตัวอักษร (trim · ตัวพิมพ์เล็ก · ไม่ยุบช่องว่าง · S11-03 ขอให้ S7 export จาก `src/core/supplier-docs`) เพื่อให้ S7 และ S11 ตัดสิน "ขอบเขตเดียวกัน" ตรงกัน · **คำถามที่ถูกอ้างโดยประเภทเอกสาร `singleInstance = false` ต้องตั้ง `evidenceScopeRequired = true` พร้อม `evidenceScope`** (lint `RISK_LINT_SCOPE_REQUIRED` · การเทียบกับ `workScopes` อย่างเดียวไม่พอเมื่อใบมี `workScopes = ["ISO 27001"]`) เพราะ `linkedRiskQuestionCodes` ผูกที่ระดับประเภท: `ISO_CERT` ผูกทั้ง RQ-IS-01 (ISO 27001) และ RQ-PRM-02 (ISO 45001) ใบฉบับเดียวจึงเติมได้เฉพาะคำถามที่ scope ตรง (GC-RSK-24) · คำนวณใหม่ทุกครั้งที่บันทึกหรือส่งสำหรับทุกคำตอบที่มี `evidenceDocumentId` รวมที่ยืนยันเป็น EXPLICIT แล้ว (เอกสารหมดอายุระหว่างทางทำให้คำตอบว่าง พร้อม event source `EVIDENCE_REVOKED` · GC-RSK-16 GC-RSK-23) · ผู้ตอบแก้ค่าของคำตอบหลักฐานไม่ได้ ทำได้แค่ "ยืนยันคำตอบ" ซึ่งเปลี่ยน source เป็น `EXPLICIT` โดยคง `evidenceDocumentId` · ระดับที่ `RiskTier.requiresExplicitAnswers = true` (HIGH) ต้องยืนยันทุกข้อจึงส่งได้ (`RISK_ANSWERS_INCOMPLETE`) ใบ HIGH ที่มีคำตอบหลักฐานจึงเป็น COMPLETED ไม่ได้และไม่นับใน G-9 โดยอัตโนมัติ · ไฟล์ประกอบคำตอบอื่นเป็น `FileLink` kind `RISK_EVIDENCE` ของ `RiskAnswer` ผ่าน allowlist และ `file-scan` ของ S7 (BR-PORTAL-07) ไม่ใช่ `SupplierDocument`

- `RiskQuestion` ไม่เก็บชื่อประเภทเอกสาร · lint ของฉบับแบบประเมินเตือนเมื่อ `linkedRiskQuestionCodes` อ้างคำถามที่ไม่มี (`RISK_LINT_UNKNOWN_QUESTION`)
- S11-12 ขอให้ชีต `Supplier_Document_Types` ของ S7 ใส่ `ISO_CERT → RQ-IS-01,RQ-PRM-02` และให้ `SP0141` มี `ISO_CERT` scope "ISO 27001" (ผ่าน agent หลัก ไม่แก้สคริปต์ของ S7 เอง)
- golden GC-RSK-14 ถึง 22 23 และ 24 (หลักฐานและความสมบูรณ์ · 76 = ใบ ISO 27001 ไม่เติม RQ-PRM-02)
- ไฟล์ `RISK_EVIDENCE` ส่งให้ AI เฉพาะคำถาม `RiskQuestion.aiReadable` ที่ผู้อัปโหลดติ๊ก `RiskAnswer.evidenceAiReadable` (BR-AI-33 · ADR-228)

## ผลที่ตามมา

- หนึ่งแหล่งความจริงของใบรับรอง (S7) · S11 อ่านอย่างเดียว ไม่สร้างคำขอเอกสารของตัวเอง
- ผู้ขาย MEDIUM/LOW ที่มีใบรับรองตอบน้อยลง · ผู้ขาย HIGH ยังต้องยืนยันทุกข้อตาม §8.12
- ถ้าผู้ใช้เลือกให้หลักฐานนับแทนทุกระดับ: ขัด §8.12 ตรงตัว จึงไม่ทำ
