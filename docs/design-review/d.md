## 1. แผนต่อหน้า

### A. `/admin/calendar` ปฏิทินทำการและวันหยุด (FR-ADM-003)

- ต้องบอก: วันทำงานและเวลาทำการปัจจุบัน (ค่าเริ่มต้นตาม A-07 จันทร์–ศุกร์ 08:30–17:30) · ว่าค่าเหล่านี้ใช้คิดกำหนดเวลาของงานอนุมัติ · การเปลี่ยนมีผลกับงานที่มอบหลังบันทึก งานเดิมคงกำหนดเวลาเดิม (AC3) · วันหยุดตั้งแต่ต้นปีนี้ · นำเข้าวันหยุดจาก Excel พร้อมรายงานแถวที่ผิด (AC2) · วันหยุดที่จะเพิ่มก่อนบันทึก เพราะเพิ่มแล้วลบหรือแก้ชื่อไม่ได้ (§10.2 ไม่มี event ลบวันหยุด) และมีผลกับกำหนดเวลาของงานที่มอบหลังจากนั้น
- ลำดับ: ฟอร์มเวลาทำการ → นำเข้าวันหยุด → รายการวันหยุด
- โครงหน้า: หัวข้อ + คำอธิบายหนึ่งบรรทัด · จอกว้าง: คอลัมน์ซ้าย = เวลาทำการ แล้วรายการวันหยุด · คอลัมน์ขวา 24rem = นำเข้าวันหยุด · มือถือ (ลำดับใน DOM): เวลาทำการ → นำเข้า → รายการ
- ฟอร์มเวลาทำการ 3 ช่อง: วันทำงาน (ช่องติ๊ก 7 วัน) · เริ่ม · เลิก (เวลาไทย) · ปุ่ม "บันทึกเวลาทำการ" · ผล "บันทึกเวลาทำการแล้ว …งานที่มอบไปแล้วคงกำหนดเวลาเดิม"
- รายการวันหยุดเป็นรายการคั่นเส้น แยกตามปี พ.ศ. (วันที่แบบไทย + วันในสัปดาห์ + ชื่อ) · หน้าว่างบอกให้นำเข้าจาก Excel
- นำเข้า 2 ขั้นจริง: (1) ลิงก์ดาวน์โหลดแม่แบบ · ปุ่มเลือกไฟล์ของเราเอง (ไม่ใช้ข้อความของเบราว์เซอร์) · ปุ่มรอง "ตรวจไฟล์" · แถวผิดแสดงทีละแถวใน Notice และไม่บันทึกอะไร · ปีที่ใส่ได้คือปีนี้ (ที่รายการเริ่มแสดง) ถึงอีก 10 ปี และข้อความบอกช่วงปีนั้น (2) หัวข้อ "จะเพิ่มวันหยุด N วัน" + รายการวันที่ วันในสัปดาห์ และชื่อ · หัวข้อ "ข้าม N วันที่มีในปฏิทินแล้ว" + ชื่อที่ปฏิทินคงไว้ · ช่องติ๊กยืนยันที่บอกว่าเพิ่มแล้วลบหรือแก้ชื่อไม่ได้ · ปุ่มหลัก "เพิ่มวันหยุด N วัน" · เลือกไฟล์ใหม่ = เริ่มขั้น 1 ใหม่

### B. `/admin/numbering` รูปแบบเลขเอกสาร (FR-ADM-004)

- ต้องบอก: รูปแบบและการรีเซ็ตของเอกสาร 4 ชนิด (PR PO GR RQ) · เลขถัดไปที่จะออกจริง · ตัวอย่างเลขถัดไปของรูปแบบที่กำลังแก้ก่อนบันทึก (AC1) และว่าเลขนั้นนับต่อจากชุดเดิมหรือเริ่มชุดใหม่ (AC3) · รหัสที่ใช้ได้ในรูปแบบ · ปัญหาของรูปแบบก่อนกดบันทึก (รหัสที่ไม่รู้จัก ไม่มี {SEQn} ไม่มีปีหรือเดือนตามการรีเซ็ต เลขที่จะชนกับเลขที่ออกไปแล้ว — AC2 AC3)
- ลำดับ: เอกสารทีละชนิดเรียง PR → PO → GR → RQ · คำอธิบายรหัสอยู่ด้านขวาบนจอกว้าง และต่อท้ายบนมือถือ
- โครงหน้า: แต่ละชนิดเป็น section คั่นเส้น (ไม่ใช่การ์ด): หัวข้อ "ใบขอซื้อ (PR)" · บรรทัด "เลขถัดไป …" · ฟอร์ม 2–3 ช่อง (รูปแบบ · รีเซ็ตเลข · แผนกตัวอย่างเมื่อมี {DEPT}) · กล่องตัวอย่างเลขถัดไปที่อัปเดตเองเมื่อพิมพ์ (ข้อความ + ไอคอน) · ปุ่ม "บันทึกรูปแบบเลข PR"
- ปัญหาของรูปแบบแสดงเป็นข้อความพร้อมไอคอนใต้ช่อง และ server ปฏิเสธซ้ำด้วยข้อความเดียวกัน

### C. `/admin/request-types` ประเภทคำขอ (FR-ADM-005 AC2)

- ต้องบอก: ประเภทคำขอตามลำดับที่ผู้ขอเห็นในหน้าเริ่มคำขอ · เปิดใช้หรือปิดอยู่ (ไอคอน + ข้อความ) · ชนิดเอกสาร · ฟอร์มฉบับที่ใช้อยู่ · ลิงก์ไปจัดการฟอร์ม
- โครงหน้า: รายการลำดับเดียว คั่นเส้น · แต่ละแถว: ชื่อ รหัส ชนิด สถานะ ฉบับฟอร์ม · ปุ่ม "เลื่อนขึ้น" "เลื่อนลง" (ข้อความ ไม่มีลูกศร) · ปุ่ม "ปิดใช้ประเภทนี้" (ขอบสี danger) หรือ "เปิดใช้ประเภทนี้" (สีหลัก) · ลิงก์ "จัดการฟอร์มของ <ชื่อ>"
- การปิดใช้ย้อนได้จากหน้าเดียวกัน จึงไม่ต้องยืนยัน แต่ข้อความผลบอกว่าผู้ขอจะไม่เห็นประเภทนี้และคำขอเดิมไม่เปลี่ยน

### D. `/admin/request-types/[code]` ฟอร์มของประเภทคำขอ (FR-ADM-005 AC1 AC3)

- ต้องบอก: ฟิลด์ของฟอร์มฉบับที่ใช้อยู่ (ชื่อตามภาษาผู้อ่าน ชนิด บังคับหรือไม่) · กฎเอกสารแนบ · ประวัติทุกฉบับ (เผยแพร่เมื่อ โดยใคร ใช้กับคำขอกี่รายการ) และว่าคำขอเดิมยังใช้ฉบับเดิม (AC3) · ดาวน์โหลดฟอร์มฉบับปัจจุบันเป็น JSON · นำเข้า JSON
- ขั้นจริง 2 ขั้น: ตรวจฟอร์ม → ยืนยันและเผยแพร่ · ขั้นตรวจแสดงสรุป (จำนวนฟิลด์ กฎ สิ่งที่เปลี่ยนจากฉบับปัจจุบัน) หรือรายการปัญหาทีละข้อพร้อมตำแหน่งใน JSON · การเผยแพร่ต้องติ๊กยืนยันก่อน (ย้อนไม่ได้ ฉบับที่เผยแพร่แล้วแก้ไม่ได้)
- โครงหน้า: จอกว้าง: ซ้าย = ฟิลด์และกฎของฉบับปัจจุบัน แล้วประวัติฉบับ · ขวา 26rem = นำเข้า · มือถือ: ฉบับปัจจุบัน → นำเข้า → ประวัติ
- ช่องข้อมูลของฟอร์มนำเข้า: วาง JSON (textarea) หรือเลือกไฟล์ .json = 2 ช่อง

### E. `/settings/delegation` รักษาการ (NEW-06 · FR-DOA-006 AC2 ส่วนเว็บ)

- ต้องบอก: ใครรักษาการแทนฉัน ช่วงไหน ครอบคลุมงานอะไร วงเงินเท่าไร สถานะ (กำลังรักษาการ · รอเริ่ม · สิ้นสุดแล้ว · ยกเลิกแล้ว เป็นไอคอน + ข้อความ) · ตั้งผู้รักษาการใหม่ · ยกเลิก · ฉันรักษาการแทนใคร
- ผู้ไม่มีตำแหน่ง: บอกว่าไม่มีอำนาจให้มอบ (BR-DLG-01) แทนฟอร์ม และยังเห็นส่วน "ฉันรักษาการแทน"
- ฟอร์ม 6 ช่อง: ผู้รักษาการ · วันเริ่ม (วันนี้หรือหลังจากนี้) · วันสุดท้าย (รวมวันนั้น) · ครอบคลุมงาน (ทุกประเภท หรือเลือกเอง) · วงเงินสูงสุด (ไม่บังคับ) · เหตุผล · ปุ่ม "ตั้งผู้รักษาการ" · ผล "ตั้งผู้รักษาการแล้ว" · รายชื่อให้เลือกส่งให้เฉพาะผู้ที่มีตำแหน่ง (ผู้ไม่มีตำแหน่งไม่ได้รับรายชื่อสมาชิก)
- โครงหน้า: จอกว้าง: ซ้าย = รายการที่ตั้งไว้ แล้ว "ฉันรักษาการแทน" · ขวา 24rem = ฟอร์ม · มือถือ: ฟอร์ม → รายการ (งานหลักมาก่อน)
- ยกเลิก: ปุ่ม "ยกเลิกการรักษาการของ <ชื่อ>" เปิดช่องติ๊กยืนยันในแถว แล้วปุ่มขอบ danger "ยืนยันยกเลิกการรักษาการ" (ย้อนไม่ได้ ต้องตั้งใหม่)
- วงเงินชิดขวา `tabular-nums` ทศนิยม 2 ตำแหน่ง · วันที่เป็น พ.ศ. ตามเวลาไทย · หน้าว่างบอกขั้นต่อไป
