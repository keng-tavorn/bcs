# งานหลัง demo จากรอบทวน D-05

สำหรับคนที่วางงานหลัง demo และคนทวนดีไซน์รอบถัดไป: ไฟล์นี้รวมทุกเรื่องที่รอบทวนล่าสุดของ D-05 (รอบที่ 6 และ 7 ใน [demo.md](demo.md))
สังเกตเห็น แต่ไม่ได้นับเป็นข้อในตารางของ D-05 เพราะรอบทวนนับเป็นข้อเฉพาะสิ่งที่ภาพของฉาก demo แสดงและขัดกับบรรทัดหนึ่งของ §9.9
เรื่องในไฟล์นี้จึงไม่ใช่ข้อของ D-05 และไม่มีเรื่องใดขวาง demo ส่วนใหญ่เป็นสถานะที่ฉาก demo ไม่ได้แสดง ถ้อยคำและรสนิยม ช่องว่างของ spec
ที่ต้องให้เจ้าของตัดสิน เทสต์ที่ยังขาด และบันทึกที่ล้าสมัย

- เรื่องเดียวกันที่รอบทวนพบหลายหน้ารวมเป็นแถวเดียว แถวที่เกี่ยวกับหลายหน้าอยู่ก่อน แล้วจึงเป็นแถวของแต่ละหน้าตามลำดับแถวใน demo.md
- ที่ไม่อยู่ในตาราง: ข้อสังเกตว่าข้อความใน demo.md ล้าสมัยหรือไม่แม่น (ปรับในการปรับตารางครั้งนี้แล้ว) · ข้อสังเกตว่างานแก้ยังไม่ commit
  (เป็นขั้นต่อไปของ D-05 ไม่ใช่งานหลัง demo) · ติ๊กสี `--primary` ของ "งบพอ" "ครบแล้ว" "ครบ" "ต่ำสุดก่อน VAT" และกล่องพร้อมส่งในฟอร์ม LIFF
  (การแก้รอบที่ 6 เปลี่ยนเป็นไอคอน Info สี `--info` แล้ว รอบทวนถัดไปจะดูจากภาพ) · คำเดา "อาจถูกลบไปแล้ว" ของ
  `requestForm.errors.NOT_FOUND` (ยังค้างในตารางเป็นส่วนที่เหลือของ `/requests/new/BUY_GOODS` ข้อ 8)
- ข้อนอกฉาก demo ที่พบระหว่างแก้ อยู่ในหัวข้อ "วิธีอ่านตาราง" ของ demo.md
