## 1. แผนต่อหน้า

### A. `/finance/invoices` งานรอใบกำกับ (invoiceConfirmation.record)

- ต้องบอก (เรียงตามความสำคัญ — งานของฉันก่อน):
  1. ใบสั่งซื้อที่รอใบกำกับ: ส่งให้ผู้ขายแล้ว รับบางส่วน รับครบ และใบที่ปิดแล้วแต่ยังถืองบไว้รอใบกำกับของที่รับแล้ว (BR-IVC-01
     BR-BUD-06) ที่ยังไม่มีใบสุดท้าย เรียงใบที่ส่งนานที่สุดก่อน · แต่ละใบ: เลข PO (ลิงก์ "บันทึกใบกำกับ PO-…") ผู้ขาย สถานะ
     (ไอคอน + ข้อความ) ส่งเมื่อ · ยอดก่อน VAT ของ PO · รับของแล้ว (มูลค่าก่อน VAT) · ใบกำกับแล้ว · ยังถืองบ
  2. ใบกำกับที่บันทึกล่าสุด: เลขที่ ผู้ขาย PO (ลิงก์) วันที่ใบกำกับ ยอดก่อน VAT VAT ยอดรวม · ใบสุดท้ายหรือไม่ · ที่มา (อ่านจาก
     ไฟล์ e-Tax หรือกรอกเอง) · ส่งออก Express แล้วหรือยัง · ผู้บันทึกและเวลา
  3. ทางไปหน้าส่งออก: "ส่งออกไฟล์ Express (ใบกำกับที่ยังไม่ส่งออก N ใบ)"
- ค้นหาด้วยฟอร์ม GET ธรรมดา (ไม่เปลี่ยนอะไร): เลข PO ชื่อหรือรหัสผู้ขาย เลขใบกำกับ
- หน้าว่าง: "ยังไม่มีใบสั่งซื้อรอใบกำกับ" + บอกว่าใบจะมาเมื่อฝ่ายจัดซื้อส่ง PO ให้ผู้ขาย · "ยังไม่มีใบกำกับที่บันทึก" + บอกให้เลือก
  PO จากรายการด้านบน · ค้นหาไม่พบ: บอกและมีลิงก์ล้างการค้นหา
- โครงหน้า: หัวข้อ + คำอธิบายหนึ่งบรรทัด + ลิงก์ไปหน้าส่งออก → ฟอร์มค้นหา → section รอใบกำกับ → section ใบกำกับล่าสุด ·
  รายการคั่นเส้น (ไม่ใช่การ์ด) · จอกว้างมีแถวหัวคอลัมน์ ยอดเงินชิดขวา · มือถือซ้อนเป็นบล็อก ยอดเงินเป็นคู่ "ป้าย — ตัวเลข"
  ชิดขวา ไม่มีตารางเลื่อนแนวนอน

### B. `/finance/invoices/[poId]` บันทึกใบกำกับของ PO หนึ่งใบ

- ต้องบอก (เรียงตามความสำคัญ):
  1. ใบไหน: เลข PO สถานะ ผู้ขายพร้อมเลขผู้เสียภาษีและสาขา (ใช้เทียบกับใบกำกับ) ส่งเมื่อ ลิงก์เปิดใบสั่งซื้อ
  2. บันทึกได้ไหม ถ้าไม่ได้บอกเหตุผลภาษาง่าย: ยังไม่ได้ส่งให้ผู้ขาย · มีใบสุดท้ายแล้ว (ไม่รับเพิ่ม) · ปิดแล้วและไม่มีงบถือเหลือ
  3. ฟอร์ม 2 ขั้นจริง (การบันทึกย้ายงบและย้อนเองไม่ได้ ขั้น 2 จึงเป็นการยืนยัน):
     - ขั้น 1 "กรอกข้อมูลใบกำกับ": ไฟล์ใบกำกับ (PDF/A-3 ที่ฝัง XML หรือไฟล์ XML) → ระบบอ่านแล้วเติม เลขที่ วันที่ ยอดก่อน VAT
       VAT ให้ตรวจ (FR-P2P-008 AC4 · BR-IVC-05) บอกยอดรวมในไฟล์และเลขผู้เสียภาษีผู้ขายที่ตรงกัน · อ่านไม่ได้หรือผู้ขายไม่ตรง →
       บอกเหตุผลภาษาง่ายและให้กรอกเอง · ช่อง เลขที่ วันที่ ยอดก่อน VAT VAT · ยอดรวมคำนวณให้ (ก่อน VAT + VAT) · ติ๊ก "ใบสุดท้าย"
       → ปุ่มหลัก "ตรวจสอบก่อนบันทึก"
     - ขั้น 2 "ตรวจสอบก่อนบันทึก" (server คำนวณด้วยกฎเดียวกับคำสั่ง — บอกล่วงหน้า §9.9 หลัก 3): สรุปใบกำกับ · VAT เทียบอัตรา
       ของ PO (ต่างเกิน 1.00 บาท = คำเตือน ไม่บล็อก BR-IVC-01) · การปันยอดลงบรรทัด PO (BR-IVC-04) · งบที่จะย้ายจากถือเป็น
       จ่ายจริงต่อบรรทัดงบ (AC2) · ยอดที่ PO ยังถือก่อนและหลัง · ถ้าเป็นใบสุดท้าย: PO ที่ปิดแล้วคืนงบส่วนที่เหลือทันที / PO ที่ยัง
       เปิดอยู่จะคืนทั้งหมดเมื่อฝ่ายจัดซื้อปิด PO (AC3 · BR-BUD-06) → ปุ่มหลัก "ยืนยันบันทึกใบกำกับ" ปุ่มรอง "กลับไปแก้ข้อมูล"
     - เลขซ้ำ (DUPLICATE_INVOICE) และยอดเกินที่ PO ถือ (INVOICE_EXCEEDS_COMMITTED) บอกเป็นภาษาง่ายพร้อมวิธีแก้ที่ขั้น 1
  4. ผลหลังบันทึก: "บันทึกใบกำกับ … แล้ว" + การปันยอดจริงจาก server + งบที่ย้ายแล้วต่อบรรทัดงบ + ผลของใบสุดท้าย + คำเตือน VAT
     (ถ้ามี) + ลิงก์ "บันทึกใบกำกับใบถัดไปของ PO นี้" / "กลับไปรายการรอใบกำกับ"
  5. ยอดของ PO (แถบข้าง): ยอดก่อน VAT อัตรา VAT VAT ยอดรวม · รับของแล้ว · ใบกำกับแล้ว · ยังถือ · งบของ PO นี้ต่อบรรทัดงบ
     (ถือไว้ · จ่ายจริง) · รายการใน PO (สั่ง · รับแล้ว · ยังถือ ต่อบรรทัด) · ใบกำกับของ PO นี้ (เลขที่ วันที่ ยอด ใบสุดท้าย ที่มา
     ไฟล์ที่เปิดได้)
- โครงหน้า มือถือ (คอลัมน์เดียว): ลิงก์กลับ → หัวเรื่อง → ข้อความสิทธิ์/สถานะ → ฟอร์ม (แถบปุ่มหลักติดล่างจอ sticky) →
  ยอดของ PO → งบ → รายการ → ใบกำกับที่ผ่านมา · จอกว้าง: ซ้าย = ฟอร์ม · ขวา 24rem = ยอดของ PO งบ รายการ และใบกำกับที่ผ่านมา

### C. `/finance/exports` ส่งออกไฟล์ Express (export.express)

- ต้องบอก (เรียงตามความสำคัญ):
  1. พร้อมส่งออก: ใบกำกับที่ยังไม่เคยส่งออกและจะเข้าไฟล์ จำนวนใบและยอดรวม (รวม VAT) · รายการ เลขที่ ผู้ขาย PO วันที่ ยอดรวม
     · ช่องติ๊ก "ตรวจรายการแล้ว ใบเหล่านี้จะถูกบันทึกว่าส่งออกแล้ว" + ปุ่มหลัก "สร้างไฟล์ Express (N ใบ)" (AC1)
  2. กันไว้ก่อน (BR-EXP-04 · AC4): ใบของผู้ขายที่ยังไม่มีรหัสเจ้าหนี้ Express จัดกลุ่มตามผู้ขาย พร้อมลิงก์ "เปิดข้อมูลผู้ขาย …"
     ไปหน้าผู้ขาย และบอกว่าฝ่ายจัดซื้อเป็นผู้เติมรหัส (§2.4 supplier.manage) แล้วใบจะเข้าไฟล์รอบถัดไป
  3. รูปแบบไฟล์ขององค์กร (settings.express · BR-EXP-01): ชนิดไฟล์ encoding รูปแบบปี คอลัมน์ตามลำดับ · ยังไม่ตั้ง → บอกให้ติดต่อ
     ผู้ดูแลระบบ และปุ่มสร้างไฟล์ไม่ทำงาน
  4. ไฟล์ที่สร้างแล้ว ใหม่ไปเก่า (AC2): สร้างเมื่อ โดยใคร จำนวนแถว ยอดรวม checksum SHA-256 เหตุผล (ถ้าเป็นการส่งออกซ้ำ) ปุ่ม
     "ดาวน์โหลด …" (ขอที่อยู่ไฟล์อายุ 5 นาทีตอนกด หลังตรวจสิทธิ์) · ส่งออกชุดเดิมอีกครั้งต้องใส่เหตุผล (BR-EXP-02) อยู่ใน
     disclosure แยกจากปุ่มหลัก
- หน้าว่าง: "ไม่มีใบกำกับรอส่งออก" + ลิงก์ไปหน้ายืนยันใบกำกับ · "ยังไม่เคยสร้างไฟล์ Express" + บอกว่าไฟล์แรกสร้างจากรายการ
  ด้านบน
- โครงหน้า: หัวข้อ + คำอธิบาย → พร้อมส่งออก (รายการ + แผงสร้างไฟล์) → กันไว้ก่อน → รูปแบบไฟล์ → ไฟล์ที่สร้างแล้ว · รายการคั่นเส้น
  ยอดเงินชิดขวา · checksum ตัดบรรทัดได้ (ไม่ใช้ monospace) · มือถือซ้อนเป็นบล็อก
