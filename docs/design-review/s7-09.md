# ตรวจหน้าจอ S7-09 หน้าภายในของใบสมัครผู้ขาย (2026-11-08)

ตรวจกับ "สิ่งที่ห้ามใช้" §9.9: การ์ดขอบ `--line` ไม่มีเงา · สถานะเป็นข้อความใน Badge และ "ค้างเกินกำหนด" มีไอคอนนาฬิกาคู่ข้อความ · ปุ่มบอกผล ("ตรวจทะเบียนแล้วส่งเข้าเส้นทางอนุมัติ" "ส่งคำเชิญทางอีเมล") · ยกเลิกใบสมัครเป็นปุ่ม danger และยืนยันด้วย AlertDialog พร้อมเหตุผล · ตีกลับใช้ Dialog พร้อมเหตุผล · รายการใบสมัครเป็นมุมมองรายการทั้งสองขนาด (ไม่มีตารางล้นจอ) · ฟอร์มเชิญไม่เกิน 8 ช่อง (ผู้ขายใหม่กับผู้ขายเดิมแยกเป็นสองแท็บ) · กรอกแทนแบ่ง 4 ขั้น

แท็บของหน้าผู้ขาย (`/suppliers/[id]`: ข้อมูล เอกสาร ผู้ติดต่อ การรับทราบ PO พอร์ทัล) และหน้างานอนุมัติ LIFF/เว็บของ `SUPPLIER_APPLICATION` ยังไม่มีภาพในรอบนี้ ส่งต่อให้ S7-18 (ตรวจดีไซน์ทั้งขั้น) · แผงเอกสารเปลี่ยนเป็นรายการใต้ 768 px แล้ว ปิดข้อสังเกตเรื่องตารางเลื่อนข้างของ S7-06
