### 16.20 S10 · จัดหา (ระยะ 2 · เส้นชัย H)

**FR ที่ครอบคลุม:** ตามแถว S10 ใน §16.8 (FR-SRC-201 ถึง FR-SRC-204 · FR-INT-201 · FR-AI-305) และเงื่อนไข §8.12 ของ FR-SRC-204 และแถว G-8 · checklist และตาราง effort ข้างล่างเขียนตาม ADR-075 จาก `docs/sub-specs/S10.md` (รายละเอียดของทุกข้ออยู่ในไฟล์นั้น) · เริ่มโค้ดได้หลังเส้นชัย C ลูกค้าตกลงขอบเขตระยะ 2 ผู้ใช้อนุมัติ sub-spec (§16.0 แถว 12) **และข้อรีวิวท้ายขั้นของ S7 (S7-19) เข้า main แล้ว** เพราะ S10 ใช้โมดูล `SUPPLIER` พอร์ทัล `SupplierContact` `PortalSession` `portalDb` `portalAuthorize` `supplierDocumentStatus` และ fixture `doa-versions-p2.yaml` ของ S7 · สายและ branch ของระยะ 2 ตัดสินตอนเริ่มระยะ 2 (ADR-075 · ร่างสมมติว่า S10 กับ S11 คนละสาย) · ข้อสุดท้ายของ agent คือรีวิวทั้งขั้นแล้วส่งเข้า main
