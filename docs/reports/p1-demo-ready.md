# รายงานความพร้อม demo ระยะ 1 — เส้นชัย A3

สำหรับเจ้าของโปรเจกต์และทีมที่จะ demo ระยะ 1 ให้ LK-RICH: อะไรพร้อมแล้ว อะไรยังรอคุณ และผลการตรวจทั้งหมด

- ข้อมูล ณ 1 พ.ย. 2569 · commit `f99fe304` บนสาขา `main` · spec ฉบับ 0.4
- ข้อมูลในระบบเป็นของสมมติทั้งหมด: องค์กร SIMEC จาก `docs/inputs/BCS_inputs_p1.xlsx` (ยังห้ามใช้ข้อมูลจริงจนกว่า OQ-19 ปิด)
- **รายงานฉบับนี้เขียนก่อน P1-11 จบ** ตามที่ผู้ใช้ขอให้ข้ามการทดสอบบน staging ไปก่อน spec ให้เขียนรายงานหลัง P1-11 จึงต้องเติมผลซ้อมบน staging ลงในรายงานนี้เมื่อซ้อมแล้ว

## สรุปสั้น

- ระยะ 1 ทำครบทุกขั้นบนข้อมูลสมมติแล้ว: ผู้ตรวจหลายฝ่ายและตัวตั้งค่า (S6) · ใบแจ้งหนี้และจับคู่ 3 ทาง (S8) · รอบจ่าย (S9) · AI ช่วยอ่านเอกสาร (S13) · ขอผ่าน LINE และแอป BCS Go (S17)
- ฉาก demo ทุกฉากหลักผ่านการเล่นอัตโนมัติบนเครื่องแล้ว **แต่ยังไม่มีใครเล่นบน staging ด้วยมือตาม runbook**
- **เส้นชัย A3 ยังไม่ถึง** เหลือ 2 ข้อของ agent (P1-11 P1-12 ซึ่งทั้งคู่รอผลซ้อมบน staging) และการซ้อมบนมือถือจริงของคุณ (P1-13)
- ยังไม่ควรขอข้อมูลจริงจาก LK-RICH จนกว่าจะซ้อมผ่าน

## รอคุณ (Blocked on me)

### 0. เปิด Docker Desktop

เปิดโปรแกรม Docker Desktop แล้วรอจนขึ้นว่าทำงานอยู่ จากนั้นบอก agent ให้รัน `pnpm verify` ใหม่

### 1. ซ้อมบน staging และซ้อมบนมือถือจริง (P1-11 · P1-13)

ทำตาม [docs/DEMO_RUNBOOK.md](../DEMO_RUNBOOK.md) ข้อ 6 จากบนลงล่าง

1. ตั้งตัวแปรของ staging ใน Vercel เอง และเตรียมมือถือตามข้อ 6.1 (ค่าลับห้ามวางในแชท)
2. บอก agent ว่าอนุญาตให้ deploy แล้วกด reset เป็น "ชุดข้อมูลระยะ 1" ตามข้อ 2 ไม่เกินประมาณ 6 ชั่วโมงทำการก่อนซ้อม การ reset ล้างข้อมูลบน staging ทั้งหมด รวมองค์กร DEMO และการผูก LINE
3. เล่นทุกฉากตามข้อ 6.4 แล้วบอก agent ว่าฉากไหนผ่านหรือไม่ผ่าน agent จะเติมตาราง "ซ้อมบน staging" แล้วติ๊ก P1-11 และ P1-12
4. ซ้อมบนมือถือจริงรวม LINE และแอป แล้วติ๊ก P1-13 เอง

เรื่องที่ agent ยังไม่รู้: ตอนนี้ข้อมูลบน staging เป็นชุดไหน เพราะ `/api/health` ไม่ได้บอก

### 2. อนุญาตให้ push เข้า main

มี commit บนเครื่องที่ยังไม่ขึ้น GitHub (runbook แบบฟอร์มข้อมูลจริง และรายงานนี้) ทุก push เข้า main จะ deploy staging อัตโนมัติ agent จึงรอคำอนุญาตของคุณก่อน commit เหล่านี้ไม่แก้โค้ดใน `src` staging จึงทำงานเหมือนเดิม
