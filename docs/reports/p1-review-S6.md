- sandbox ของ S6-21 ได้ค่าตั้งขององค์กร production (ปฏิทิน SLA เขตเวลา เกณฑ์งบ) โดยปิด LINE เพราะค่าตั้งว่างไม่ผ่าน schema · ไม่มีผัง DOA สมาชิก หรือข้อมูลธุรกิจใดคัดลอกมา (BR-UAT-01 BR-UAT-04 · ADR-110)

- การตรวจ `ai.doaDraft` กับการแยกผู้ดูแล DOA เป็นของสาย 3 (S13) · ฝั่ง S6 ส่ง `DOA_ADMIN_SEPARATED` ให้แล้ว
