## S7 (รอบตรวจของ ADR-075 · 2026-11-01)

ไฟล์ที่แก้: `docs/sub-specs/S7.md` · `docs/drafts/p2/S7-spec-additions.md` · `docs/decisions/ADR-181.md` `ADR-182.md` `ADR-183.md` `ADR-185.md` `ADR-186.md` `ADR-189.md` `ADR-190.md` · ตัวเลข golden ที่เพิ่มหรือเปลี่ยนคำนวณซ้ำด้วยสคริปต์ Python (`datetime` `decimal` ไม่ใช้ float) ใน scratchpad ของผู้แก้ (`s7-fixer/golden_fix.py` · ไม่ commit) · หลังแก้: โครง `##` ครบ 16 หัวข้อ (15 ของบรีฟ + สถาปัตยกรรม) · บล็อก YAML ทั้ง 7 parse ได้ · GC-SUP-09 ถึง 53 ไม่ซ้ำไม่กระโดด (suite `supplier-onboarding` 29 เคส · `supplier-documents` 16 เคส) · เลข OQ ขยายเป็น 181–193 และ ADR ยังเป็น 181–190 ต่อเนื่อง

การตัดสินใจหลักของรอบแก้ (ทางที่เลือกเมื่อผลตรวจเสนอหลายทาง):

- บัญชีธนาคารจากพอร์ทัล (BLOCKER): เลือกทาง (ก) เพิ่มคำสั่ง `bankAccountChange.claim` ของ S9 และทำ `submittedById` เป็น nullable เฉพาะ `source = PORTAL` ด้วย CHECK · DRAFT จากพอร์ทัลและจากการอนุมัติใบสมัครมี `submittedById` ว่างจน FINANCE claim · ไม่สร้างตาราง `BankAccountProposal` (ทาง ข) เพราะเท่ากับทางที่สองของบัญชี
- ขอข้อมูลเพิ่มของใบสมัคร: เลือกทาง (ก) `allowsRequestInfo: false` และใช้ `approval.return` ตีกลับ ไม่แก้สัญญากลางและ `decide.ts`
- องค์กรของพอร์ทัล: route ทุกตัวมี `[org]` ใน path (`Organization.code` ตัวพิมพ์เล็ก) cookie path `/portal/<org>` และ route handler ย้ายไป `/portal/[org]/api/*` (แก้ทั้ง SPEC-02 และ AUTHORITY-06 ในคราวเดียว) · rate limit แยกเป็น `PortalRateLimit` (tenant) และ `PortalIpRateLimit` (global) ไม่ขอยกเว้น INV-TEN-02
- `Event.actorSupplierContactId`: ตัดสินตอนนี้ว่าเพิ่มได้ทันทีเพราะ main ยังไม่มี `EventSeal` · ตัดเกณฑ์ `audit-verify` ออกจาก S7-01 · ADR-183 บันทึกว่า seal ของ S5-14/NEW-05 ต้อง hash จากรายการคอลัมน์คงที่
- AI: `BANK_BOOK.aiReadable = false` และ `VAT_CERT` อ่านเฉพาะ JURISTIC (`aiReadablePayeeTypes` · ตรวจต่อฉบับ) · GC-AI-95 เปลี่ยนเป็นเคส "ไม่เรียก agent" · ชุดประเมินไม่มีสมุดบัญชี · OQ-186 บอกผู้ใช้ชัดว่าภาพทั้งใบส่งให้ Anthropic
- SoD: ผู้ขัดกันของ `SUPPLIER_APPROVAL` = ผู้เชิญ ผู้กรอกแทน ผู้ส่งเข้าเส้นทาง ผู้ยืนยันเอกสาร (OQ-193 ค่าเริ่มต้น "ไม่ได้") · เพิ่ม OQ-192 (ผู้ติดต่อใหม่ของผู้ขายเดิม · ค่าเริ่มต้นแจ้งอีเมลในทะเบียน + หน่วง 2 วันทำการ · BR-SUP-17)
- PDPA: เปลี่ยน consent เป็นประกาศความเป็นส่วนตัว (`privacyNoticeAcceptedAt`) · เพิ่ม BR-PORTAL-09 anonymize · ขยาย OQ-188 ให้ครอบฐานการประมวลผล สิทธิ์เจ้าของข้อมูล ROPA และ sub-processor (S7-20 S7-22)
