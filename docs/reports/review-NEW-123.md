## ก่อนรีวิว (2026-11-03)

- ข้อมูลระยะ 1 (`pnpm db:reset:p1`) ทำให้เห็นว่างานเหมา "งานติดตั้งระบบประปาและสุขาภิบาล" 1 งาน 3,746,200.00 บาท เทียบกับงานเหมาของโครงการอื่น 313,700.00 ถึง 1,956,300.00 บาท จะขึ้นเป็น "ถูกลงได้ 2,230,000.00 บาท" · แก้ใน `cebb7da2`: "แพงกว่าประวัติ" และ "หลายแผนก" นับเฉพาะสินค้า (GC-SAV-16) และยอดทุกจำนวนเขียนเป็นเงื่อนไข · การตัดงานบริการมีผลจริงเมื่อ NEW-96 ตั้งชนิดของบรรทัด
- `pnpm verify` ด่าน unit ล้มที่ `tests/unit/ai-adapter.test.ts` "[BR-AI-11] every purpose has a SYNTHETIC gate": purpose ใหม่ `SAVINGS_NOTE` ต้องมีรายงานการประเมินจริงก่อนมีอยู่ ซึ่งเสียค่า API ที่ผู้ใช้ยังไม่อนุญาตสำหรับข้อนี้ · `6a314009` ถอดคำอธิบายของ AI ออก (โค้ดและเทสต์ยังอยู่ใน `25345e4a`) และย้ายไป NEW-136
