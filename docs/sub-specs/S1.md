## แบบแผนโค้ด (ทุก agent อ่านก่อนเริ่ม)

- **ชั้นของโค้ด §4.2/§4.10:** ตรรกะอยู่ใน `src/core` (pure) และ `src/server/services` · `src/app` `src/channels` เป็น adapter บาง · Prisma ใช้ได้เฉพาะ `src/server/db` · raw SQL เฉพาะ `src/server/db/sql`
- **core:** ห้าม I/O `Date.now()` `new Date()` ไม่มีอาร์กิวเมนต์ `Math.random()` `process.env` · import ได้แค่ core + zod decimal.js date-fns @date-fns/tz · รับ `now` เป็นพารามิเตอร์ · คืนผลพร้อมเหตุผลแบบมีโครงสร้าง (ให้ UI แปลเป็นไทย/อังกฤษ)
- **service:** `export async function doThing(ctx: Ctx, input: Input): Promise<Result<Dto>>` · ทุกการเปลี่ยนสถานะผ่าน `runCommand()` · ตรวจสิทธิ์ใน service เสมอ · คืน DTO ไม่คืน model ของ Prisma
- **เงิน:** BigInt สตางค์ (ชื่อฟิลด์ลงท้าย `Satang`) · อัตราเป็น basis point (`Bp`) · DTO เงินเป็น `{ amount: "12345.50", currency: "THB" }` ผ่าน helper เดียว · ห้าม `number` กับเงิน
- **เวลา:** นาฬิกาธุรกิจ `ctx.now` (inject ได้) แยกจากนาฬิกาความปลอดภัย (เวลาจริง) · เก็บ UTC แสดง Asia/Bangkok ปี พ.ศ.
- **id:** `newId()` (UUID v7) · **error:** รหัสตาราง §14.2 เท่านั้น ข้อความอยู่ใน `messages/src/*/errors.json`
- **event:** ชื่อ `<aggregate>.<past_verb>` · schema แยกไฟล์ต่อ aggregate ใน `src/server/events/schemas/` · ข้อมูลใน event ห้ามมีข้อความอิสระที่อาจมีข้อมูลส่วนบุคคล
- **ข้อความหน้าจอ:** ห้ามฝังภาษาไทยในโค้ดหน้าจอ (`bcs/no-thai-literal`) · ใส่ key ทั้ง th และ en
- **export:** ห้าม default export ยกเว้นไฟล์ที่ Next.js/next-intl บังคับ · ชื่อไฟล์ kebab-case · component PascalCase
- **เทสต์:** ชื่อมีแท็ก `[FR-xxx-nnn/ACn]` หรือ `[GC-…]` · ห้าม `.skip/.only/.todo` · integration ใช้ Postgres จริง ห้าม mock ฐานข้อมูล · แต่ละเทสต์สร้างองค์กรของตัวเอง
- **commit:** `feat(<scope>): S1-xx <สรุป>` (Conventional Commits) · ติ๊กใน commit แยก `docs(spec): tick S1-xx`
