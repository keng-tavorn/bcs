# S16 · หน้าจอใหม่แบบใกล้ Zip ในโทนเขียว — sub-spec

เอกสารนี้ขยาย §16.12 สำหรับการลงมือ · spec.md มีลำดับเหนือกว่าเสมอ ถ้าขัดกันให้ยึด spec แล้วแก้ไฟล์นี้

## ขอบเขต

ข้อ `[demo]` ของ §16.12: S16-01 ถึง S16-13 (เส้นชัย A2) · FR ใน §8.13: FR-PLT-013 FR-PLT-014 FR-VIS-006 FR-VIS-007 FR-INT-010 FR-INT-011 FR-INT-012 · FR-INT-013 AC1–AC3 · และข้อ `[demo]` ที่เพิ่มใน §16.11 ตั้งแต่ NEW-72

ไม่อยู่ในขอบเขต A2: S16-14 (`[go-live]` · FR-INT-013 AC4–AC5 การกล่าวถึงด้วย @ และสวิตช์แสดงกิจกรรม) · S16-15 (`[คน]` ผู้ใช้ลองเอง) · ทุกอย่างที่ NG-13 ตัดออก (tour pop-up ที่เด้งเอง ปุ่มแชทลอย Cards RFx Surveys)

**Demo ของขั้น:** ตามบรรทัด "Demo:" ท้าย §16.12 (req_con เริ่มคำขอจากหน้าแรกและ ⌘K → vp_ops อนุมัติจากแถบตัดสิน → ceo เปิด `/insights`) · ฉาก demo เดิมทุกฉากในชีต `Demo_Script` ต้องผ่านบนหน้าจอใหม่ด้วยผู้ใช้ ยอด และผลที่คาดเดิม
