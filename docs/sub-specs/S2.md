# S2 · DOA และคำขอ — sub-spec

## ขอบเขต

S2-01 ถึง S2-17 (§16.4) และ NEW-06 (หน้าเว็บตั้งรักษาการ) · FR: FR-DOA-001 ถึง 008 · FR-DOA-010 · FR-INT-001 ถึง 003 · FR-INT-005 ถึง 009 · FR-ADM-002 ถึง 005 · FR-NOTI-001 · FR-PLT-007 AC3 · golden: money vat-rate thai taxid numbering doa doa-lint sod delegation sla forms quotations

**Demo ของขั้น:** req_con สร้างคำขอ 45,000 บาท → เห็นเส้นทางไป VP พร้อมคำอธิบาย → ส่ง → vp_ops อนุมัติบนเว็บ → ไทม์ไลน์แสดง "DOA-DEMO ฉบับ 1 ข้อ PR-02" · dm_con ขอเอง 15,000 บาท → ถูกยกไป VP · ตั้งรักษาการ dm_con → asst_con แล้วส่งคำขอ 10,000 บาท → งานไป asst_con · ORG_ADMIN เสนอแต่งตั้ง VP คนใหม่ของ OPS → CEO อนุมัติด้วย TOTP → เมื่อมีผล งานค้างของ VP ย้ายไปคนใหม่

**สถานะร่าง (2026-10-03):** ระหว่างรอ S1 ปิด orchestrator ร่าง engine บริสุทธิ์ทุกตัวของคลื่น 1 ไว้ใน `scratch/s2/` (money vat thai taxid numbering doa sod delegation sla forms quotations และตาราง state machine ของ S2-09) ผ่าน golden ของ spec ครบทุกเคสและ coverage ครบยกเว้น money · คลื่น 1 จึงเปลี่ยนเป็น **ตรวจแบบอิสระ**: agent เขียนเทสต์ money vat budget จาก §7 โดยไม่เห็นโค้ด (กติกาเงิน) · เทียบผลกับ implementation อ้างอิงใน `scripts/spec_check.py` ด้วย input สุ่มนอก golden · ตรวจตาราง state machine กับ §6.4 ทีละแถว · agent หักล้างหาเคสขอบที่ golden ไม่มี แล้วจึงย้ายเข้า `src/core` และ `tests/golden` ใน commit ของแต่ละข้อ

ข้อ S2 ติ๊กตามลำดับใน §16.4 เมื่อเสร็จเมื่อของข้อนั้นผ่านจริงและ `pnpm verify` ผ่าน · golden YAML เข้า `tests/golden` ใน commit เดียวกับ engine ของมัน (ด่าน golden-drift ตรวจทุกไบต์)

## interface ระหว่าง engine (สัญญาของคลื่น 1)

```ts
// src/core/money · src/core/vat (S2-02) — ตาม §7.1 ทุกฟังก์ชัน pure
export function parseBaht(text: string): Satang                      // "20000.01" → 2000001n · ปฏิเสธเกิน 2 ตำแหน่ง
export function rateFor(date: string /* YYYY-MM-DD เวลาไทย */, rates: TaxRateSnapshot[]): { rateBp: number } | DomainError // TAX_RATE_NOT_CONFIGURED
export function taxDateOf(at: Date): string

// src/core/delegation (S2-06) — resolveRoute เรียกตัวนี้กับผู้อนุมัติทุก step
export function delegateFor(
  approverMemberId: string,
  context: { documentType: DoaDocumentType; basisAmountSatang: Satang | null; at: Date; conflictMemberIds: readonly string[] },
  delegations: readonly DelegationSnapshot[],
): { assigneeMemberId: string; principalMemberId: string | null; notifyOrgAdmin: boolean }
export function validateNewDelegation(input: NewDelegation, existing: readonly DelegationSnapshot[], holders: OrgSnapshot): DomainError | null
// NOTHING_TO_DELEGATE · OVERLAPPING_DELEGATION · ผู้รักษาการต้อง ACTIVE และไม่ใช่ผู้มอบ (BR-DLG-01 ถึง 05 · ADR-038 ข้อ 6–7)

// src/core/sod (S2-06)
export function checkSod(action: SodAction, facts: SodFacts, policy: SodPolicy): { ok: true } | { error: 'SOD_VIOLATION'; rule: string }

// src/core/doa (S2-05)
export function resolveRoute(input: RouteInput, policy: { versions: DoaVersionSnapshot[]; org: OrgSnapshot; delegations: DelegationSnapshot[] }): RouteResult | DomainError
export function lintDoaVersion(version: DoaVersionSnapshot, org: OrgSnapshot, at: Date): { errors: LintIssue[]; warnings: LintIssue[] }
export function boundaryTable(version: DoaVersionSnapshot, documentType: DoaDocumentType): Array<{ amountSatang: Satang; ruleCode: string }>

// src/core/sla (S2-07) — ตาม sla.yaml
export function addBusinessMinutes(from: Date, minutes: number, calendar: BusinessCalendar): Date
export function businessMinutesBetween(from: Date, to: Date, calendar: BusinessCalendar): number
export function resumeDue(input: { assignedAt: Date; slaMinutes: number; pausedAt: Date; resumedAt: Date }, calendar: BusinessCalendar): Date
export function remindAt(input: { assignedAt: Date; slaMinutes: number; remindPct: number }, calendar: BusinessCalendar): Date

// src/core/forms (S2-08 · S2-17)
export function evaluateForm(form: FormSchema, input: FormInput): { ok: true; droppedFields: string[] } | { error: 'ATTACHMENT_RULE_FAILED' | 'VALIDATION_FAILED'; rule?: string; missing?: string[] }
export function compareQuotations(quotes: QuoteInput[], selectedRef: string, rateBp: number, nonLowestReason?: string): QuoteResult
```

`DomainError` = `{ error: ErrorCode; ...รายละเอียดที่มีโครงสร้าง }` เพื่อให้หน้าจอแปลเป็นไทยและอังกฤษ (§14.2)
