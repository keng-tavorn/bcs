## core/budget (สัญญาของคลื่น 1)

state ของบรรทัดงบหนึ่งบรรทัด: ยอดสี่ bucket + allocation ต่อเอกสาร (บรรทัดคำขอและบรรทัด PO) · ทุก operation เป็นฟังก์ชันบริสุทธิ์ที่คืน state ใหม่พร้อมรายการเคลื่อนไหว (from to amount source) หรือ error (`BUDGET_INSUFFICIENT` พร้อมยอดคงเหลือและยอดที่ขาด · `BUDGET_LINE_CLOSED` · `INVOICE_EXCEEDS_COMMITTED`) โดย state เดิมไม่เปลี่ยน · operation: fund reserve release submitPo approvePo rejectPo cancelPo actualize closePo ตาม §7.7 · property test ตรวจ INV-BUD-01 ถึง INV-BUD-03 และยอด bucket เท่ากับผลรวม allocation หลังทุก operation
