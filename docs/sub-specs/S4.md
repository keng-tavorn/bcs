# S4 · PO และตรวจรับ — sub-spec

เอกสารนี้ขยาย §16.6 สำหรับการลงมือ · spec.md มีลำดับเหนือกว่าเสมอ ถ้าขัดกันให้ยึด spec แล้วแก้ไฟล์นี้

## ขอบเขต

ข้อ `[demo]` ของ §16.6: S4-01 ถึง S4-11 · S4-15 · S4-17 · FR: FR-P2P-001 ถึง 010 · FR-PLT-009 · FR-VIS-001 ถึง 004 · FR-NOTI-002 · FR-SUP-001 AC1–AC3 · golden: consolidation.yaml receiving.yaml invoice-confirmation.yaml (และ budget.yaml GC-BUD-01 ถึง 05 ผ่าน service จริงใน S4-04)

ไม่อยู่ในขอบเขต demo: S4-12 S4-13 S4-14 S4-16 S4-18 (`[go-live]`) · ฟังก์ชันคำนวณของ grni.yaml และ wht.yaml ทำแล้วใน NEW-18 โดยไม่มีหน้ารายงาน

**Demo ของขั้น:** คำขอที่อนุมัติแล้ว → รวมเป็นร่าง PO → COO อนุมัติ → PO ส่งอีเมลพร้อม PDF → ผู้ตรวจรับบันทึก GR บางส่วนพร้อมรูป → อนุมัติ variance → การเงินยืนยันใบกำกับ → ส่งออกไฟล์ → dashboard แสดงยอดตัดจริง (การนำเข้า Express กับลูกค้าคือ S4-14 `[go-live]`)
