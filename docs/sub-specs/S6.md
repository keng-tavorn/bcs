เอกสารนี้ขยาย §16.14 สำหรับการลงมือ · spec.md มีลำดับเหนือกว่าเสมอ ถ้าขัดกันให้ยึด spec แล้วแก้ไฟล์นี้

## ขอบเขต

**FR (19):** FR-WF-101 ถึง FR-WF-104 · FR-INT-101 ถึง FR-INT-104 · FR-DOA-101 ถึง FR-DOA-104 · FR-ADM-101 · FR-BUD-101 ถึง FR-BUD-104 · FR-VIS-101 · FR-PLT-101 · เงื่อนไข §8.12 ของ FR-INT-101 และ FR-DOA-101 เป็น AC แล้ว

**นอกขอบเขต:** ตัวสร้าง workflow แบบลากวาง (NG-4 · FR-WF-301 ใน S15) · e-Memo สัญญา ใบสำคัญจ่าย (FR-DOA-301) · อนุมัติเกินงบของ PO (ส่วนต่างตอนส่ง PO ยัง `BUDGET_INSUFFICIENT` ตาม BR-BUD-05 · แก้ PO อยู่ S8 FR-AP-107) · ผู้ตรวจจากแบบประเมินความเสี่ยง (FR-RSK-202 ใน S11) · `PreferredSupplier` (S10) · AI ทุกชนิด (EG-1 · ทุก FR ของขั้นนี้ทำงานครบเมื่อ `AI_ENABLED=false`) · รายงาน R-01 ถึง R-07 (OQ-09)

**ขึ้นกับ:** P1-07 บน main ตามหัวข้อ "ฐานร่วมของทุกสาย (P1-07)" ของ `docs/sub-specs/P1.md` (รายการที่รับอยู่ท้ายหัวข้อ "Entity และ migration") · P1-02 (seed SIMEC: History สองปีงบ ผู้ใช้ `dm_leg` `dm_qse` `dm_fin` `cfo`) · โมดูล `CORE` เท่านั้น: ทุกคำสั่งของขั้นนี้ไม่เรียก `requireModule` · DOA ฉบับที่มีผลไม่มีข้อของชนิดเอกสารที่ต้องใช้ → ไม่แสดงปุ่มและคำสั่งได้ `DOA_NOT_CONFIGURED` โดยไม่จองหรือเติมงบ (องค์กร DEMO ไม่มีข้อ BT OB จึงไม่เห็นปุ่มและ `@demo` ไม่เปลี่ยน) · S17 ในสายเดียวกันใช้ route view ราคาอ้างอิง และหน้างาน LIFF ของขั้นนี้

## Demo ของขั้น

ผู้ใช้และยอดจาก `scripts/inputs_p1/` (บริษัท SIMEC · DOA-SIMEC ฉบับ 1 · ฐาน GROSS)

1. **ผู้ตรวจคู่ขนาน:** `pm_p07` ขอจ้างเหมา SUB-010 งานถนนแอสฟัลต์ 9,500 ตร.ม. × 260.00 = 2,470,000.00 + VAT 172,900.00 = 2,642,900.00 (บรรทัดงบ P07-SUB) → เส้นทาง: ขั้น 1 ผู้ตรวจ RV-03 `dm_leg` · RV-04 `dm_qse` · RV-05 `dm_fin` (ครบทุกฝ่าย) → ขั้น 2 PR-03 `ceo` · `dm_qse` กด "ผ่าน" ในการ์ด LINE · `dm_leg` ขอข้อมูลเพิ่มแล้วผ่าน · `dm_fin` ผ่านบนเว็บ → `ceo` ได้งานพร้อมแผงราคาอ้างอิงของ SUB-010 และช่วงใบเสนอราคา
2. **ตั้งค่า workflow:** `admin2` คัดลอก WF-SIMEC ฉบับ 1 เป็นร่าง ลดเกณฑ์ RV-03..05 เป็นเกิน 500,000.00 → ทดลองส่งงานจ้างเหมา 800,000.00 เห็นว่าฉบับที่มีผลไม่มีผู้ตรวจ ฉบับร่างมี 3 ฝ่าย · ย้อนทดสอบ 90 วันบอกจำนวนคำขอที่จะได้ผู้ตรวจเพิ่ม → ส่ง → `ceo` อนุมัติตามข้อ DOA-CHG-01 พร้อม PIN
3. **ย้อนทดสอบ DOA:** `admin2` ร่าง DOA-SIMEC ฉบับ 2 เพิ่มช่วงขอซื้อ (100,000, 1,000,000] → COO → ย้อนทดสอบ 90 วัน: น้ำมันรายเดือนของ `eqp_02` (650,000.00 + VAT = 695,500.00) ย้ายจาก `ceo` ไป `coo` · งานของ `ceo` ลดลงตามจำนวนเอกสาร → ส่ง → `ceo` อนุมัติ → ก่อนถึงวันมีผล `admin2` ขอถอน → `ceo` อนุมัติการถอน → ฉบับ 1 มีผลต่อ
